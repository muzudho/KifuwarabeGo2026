# 盤の役割設計

## 基本方針

Kifuwarabe Go 2026では、画面に現れる囲碁盤を役割によって次の3種類に分けます。

1. **対局の盤**
   - 実際の対局状態を保持します。
   - 時計、手番、思考エンジン、合法手、終局判定などを扱います。
   - ライブ対局中は、ホワイトボードを開いてもバックグラウンドで対局を継続します。

2. **検討の盤**
   - ホワイトボード画面で使用する、元の盤から複製した独立盤です。
   - `PLAY` による合法手の検討と、`BLACK`、`WHITE`、`ERASE`、`CLEAR BOARD` による盤面編集を扱います。
   - 元の対局、観戦、棋譜レビューの盤を変更しません。
   - `DISCARD` では検討盤だけを破棄し、開く前に見ていた局面へ戻ります。

3. **観戦の盤**
   - 保存棋譜のレビュー、ローカル対局のリプレイ、CGOS観戦など、既存の棋譜を読み取り中心で表示します。
   - 手数移動、チャート、コメント表示を扱います。
   - 棋譜レビューの `USE POSITION` など、利用者が明示的に採用した場合だけ別用途へ局面を渡します。

## 共通化するもの

3種類の盤は役割と状態を分離したまま、利用者が同じ操作感で扱えるように次の表示・操作部品を共通化します。

- 盤、石、座標、最新着手リングの描画
- 棋譜の手数移動ボタンとシーク操作
- 評価値チャートと棋譜コメント
- 現在局面から検討盤を開くホワイトボードアイコン

## 統合しないもの

画面の見た目が似ていても、対局、検討、観戦の状態オブジェクトは統合しません。

特に棋譜レビューを対局中モードとして動かすと、時計更新、思考エンジン、着手受付、終局判定が意図せず働く可能性があります。そのため、棋譜レビューは `Reviewing`、検討盤は独立した `VariationEditing`、実対局は `Playing` として役割を保ちます。

この分離により、画面部品を再利用しながら、元の対局や棋譜を誤って変更しないことを優先します。
