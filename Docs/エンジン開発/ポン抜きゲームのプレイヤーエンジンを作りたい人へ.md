# ポン抜きゲームのプレイヤーエンジンを作りたい人へ

## 役割

Player Engineは黒または白を担当し、GUIから受け取った局面で次の着手を選びます。初期局面作成や「アゲハマ20個で終局」の判定はApp Provider Engineの役割なので、プレイヤーへ実装する必要はありません。同じ実行ファイルがプロバイダー機能も備えていて構いません。

## 必要な標準GTP

通常の思考エンジンとして、少なくとも次のGTPコマンドへ対応してください。

- `protocol_version`
- `name`
- `version`
- `known_command`
- `list_commands`
- `boardsize`
- `clear_board`
- `komi`
- `play`
- `genmove`
- `quit`

盤サイズは現在9路です。`genmove black`または`genmove white`へ、GTP座標または `pass` を返してください。

## 初期局面の受け取り

ポン抜きは空の盤から始まるとは限りません。Kifuwarabe Go 2026は、対応エンジンに原子的指定局面拡張を使って初期配置を同期できます。

```text
kfw-begin-position
kfw-add-black D4
kfw-add-white E4
kfw-set-to-play black
kfw-commit-position
```

正式コマンドは次の6個です。

- `kfw-begin-position`
- `kfw-add-black`
- `kfw-add-white`
- `kfw-set-to-play`
- `kfw-commit-position`
- `kfw-abort-position`

準備中は実対局盤を変更せず、`kfw-commit-position`が成功した時だけ準備盤を採用してください。詳しい原子性とエラー処理は[きふわらべ原子的指定局面GTP拡張仕様](../設計/きふわらべ原子的指定局面GTP拡張仕様.md)を参照してください。

この拡張へ未対応の場合、GUIが対応可能な別の初期局面同期方式を選ぶことがあります。ただし、自由な黒白初期配置に対応するには、この拡張への対応を推奨します。

## 対局中

GUIは相手の着手を標準GTPの `play` で通知し、自分の手番で `genmove` を呼びます。

```text
play black A3
genmove white
```

プレイヤーはポン抜き固有の `kfw-listen-move` を受け取りません。このコマンドはGUIからプロバイダーへ送られます。プレイヤーは合法手の生成に集中できます。

ポン抜きでは相手の石を取ることが直接の勝利条件なので、通常の地合いだけでなく、連の呼吸点、アタリ、逃げ、シチョウなどを重視する戦略を試せます。
