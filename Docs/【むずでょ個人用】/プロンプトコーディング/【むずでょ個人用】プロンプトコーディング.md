```plaintext
以下の **** クラスって、  
D:\****\****.cs

ラッピングしてるだけだろ（＾～＾）？ 要らないなら消してくれだぜ（＾～＾）  
```


## 進捗付き移行

例１：  
```plaintext
じゃあ、それを移行計画としてドキュメントに書き出してくれだぜ（＾▽＾）  
今分かっている残っているもの、今分かっている終わっているものを、  
進捗が分かるように書き出してくれだぜ（＾▽＾）  
```

例２：  
```plaintext
GoScreenRenderer クラスには、  
D:\github.com\muzudho\KifuwarabeGo2026\KifuwarabeGo2026.Gui\Presentation\GoScreenRenderer.cs  
これは共通部品ではないだろ、というプロパティやメソッドがまだ残ってるはずだぜ（＾～＾）  
棚卸して、移行計画のドキュメントを書いてくれだぜ（＾▽＾）  
今分かっている残っているもの、今分かっている終わっているものを、  
進捗が分かるように書き出してくれだぜ（＾▽＾）  
```

例３：  
```plaintext
じゃあ、それを棚卸して、移行計画としてドキュメントに書き出してくれだぜ（＾▽＾）  
今分かっている残っているもの、今分かっている終わっているものを進捗が分かるように、  
テキストファイルに書き出してくれだぜ（＾▽＾）  
```

書式：  
```plaintext
おー、分かりやすいぜ（＾▽＾）！  
じゃあ、この移行計画を進めてくれだぜ（＾▽＾）！  
D:\****\****移行計画.md  
終わったら、ドキュメントを以下のフォルダーへ移動してくれだぜ（＾▽＾）！    
D:\github.com\muzudho\KifuwarabeGo2026\KifuwarabeGo2026.Gui\Docs\開発\完了\  
```

* 終わったらどうするかまで指示に含めること（＾▽＾） そうすると最後までやってくれるぜ（＾▽＾）！

例１：  
```log

D:\github.com\muzudho\KifuwarabeGo2026\KifuwarabeGo2026.Gui\Docs\開発\完了\  
```

例２：  
```log
おー、分かりやすいぜ（＾▽＾）！  
以下の移行計画を進めてくれだぜ（＾▽＾）！  
D:\github.com\muzudho\KifuwarabeGo2026\KifuwarabeGo2026.Gui\Docs\開発\GoScreenRenderer 残存責務移行計画.md

```

例３：
