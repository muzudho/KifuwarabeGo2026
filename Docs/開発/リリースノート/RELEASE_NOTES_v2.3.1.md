# Kifuwarabe Go 2026 v2.3.1

v2.3.0で追加した棋譜コメントとホワイトボードを、より見つけやすく使いやすくするための微調整リリースです。

## 主な変更

- サンプル思考エンジンの通常着手へ、`A1に打ったぜ（＾～＾）` の形式の棋譜コメントを追加
- サンプル思考エンジンのパスにも棋譜コメントを追加
- チャートポップアップのコメント表示を初期状態で有効化
- ローカル対局の結果画面へホワイトボードアイコンを追加
- 終了局面から独立ホワイトボードへ移り、検討・盤面編集できるように変更

## 配布物

- GUI版: `KifuwarabeGo2026.GameOasis.Gui-v2.3.1-win-x64.zip`
- Engine版: `KifuwarabeGo2026.Engine-v2.3.1-win-x64.zip`

GUIとEngineの両方を使う場合は、2つともダウンロードしてください。
