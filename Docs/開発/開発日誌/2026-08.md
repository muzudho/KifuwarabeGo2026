### 連解析系と計測系

- 連解析系を`REN INDEX LENS`、`REN RECTANGLE LENS`、`REN NETWORK LENS - BASIC`、`REN NETWORK LENS - EYE MODE`として整理しました。
- REN NETWORKのエッジは、黒連と空連を黒、白連と空連を白、黒連と白連を背景に近い低彩度の青で描き、接続の種類を表現します。
- 計測系へ`REN AREA`、`BOUNDARY COUNT`、`BOUNDARY EMPTY COUNT`、`BOUNDARY OPPONENT COUNT`、`ADJACENT EMPTY AREA`、`ADJACENT OPPONENT AREA`を追加しました。

- 境界の交点へ伸びる線と丸マーカー、隣接する連へ伸びる線と四角マーカーを使い、重複除去と集計範囲を視覚化しました。
- 複数の足先は時計回りの風車式にずらし、線を始点から退避済みマーカーへ直接結ぶことで重なりを抑えました。
- 隣接連は境界接触点のうち行優先の最小インデックスを代表点として選び、決定論的に一意な関係線を描きます。
- 数値色を意味へ対応させ、空点・空連は黄色、自連は自連色、相手連は相手色、複合境界数は自連色と相手色の二色で表示します。
- 3桁の面積値は2桁相当の横幅へ自動縮小し、19路盤の大きな空連でも交点内へ収めます。
- Board Lens実装を`Presentation/Shared/Board/Lens`へ集約しました。

### ポン抜きプレイヤーの強化

- Board Lensと同じ`GoBoard.ParseRens()`を使う`PonnukiMovePrioritizer`をEngineへ追加しました。
- 合法手を仮着手し、捕獲数、着手後の自連面積、隣接する全相手連面積から候補手を優先度付けします。
- 最も多くの相手石を打ち上げられる手を最優先し、同じ捕獲数なら自連面積が隣接相手連面積を上回る接触手を優先します。
- 次に相手へ接触しない通常手を選び、安全な候補がない場合だけ危険な接触手を残します。
- 同じ優先度の候補内では、従来のNormalランダムまたは星領域ランダムを維持します。
- 二石取りが一石取りより優先される局面と、強い接触が通常手・危険な接触より優先される局面をWindowsスモークへ追加しました。
