# 文房具UIライブラリー切り出し作業

作成日: 2026-08-16  
状態: 完了

## 目的

文房具UIとその共通描画基盤を独立した `KifuwarabeGo2026.StationeryUI` ライブラリーとしてビルドする。
`KifuwarabeGo2026.GameOasis.Gui` は文房具UIを所有せず、文房具UIを使って［きふわらべの碁2026］を実装するアプリケーション側にする。

## 境界

文房具UIライブラリーへ移す責務:

- 文房具UIのコントロールと共通ダイアログ。
- MonoGame上の共通Canvas、仮想画面、動的文字描画。
- 文房具UIが必要とするクリップボード、文字ラスタライズ、文字入力イベントの抽象。

Gui.Coreへ残す責務:

- 囲碁盤、対局、棋譜、CGOSなどのアプリケーション機能。
- GUI更新処理とGUI更新専用進捗ダイアログ。
- 文房具UIを組み合わせる画面、Presenter、Renderer。
- StickyNoteを現在のGUI画面状態へ結び付ける処理。

## 完了条件

- `KifuwarabeGo2026.StationeryUI.dll` が独立して生成される。
- Gui.Coreの出力がStationeryUI DLLを参照する。
- StationeryUIからGui.Coreへのプロジェクト参照がない。
- GUI更新専用型など、アプリ固有型がStationeryUIへ混入しない。
- ソリューション全体が警告0・エラー0でビルドできる。

## 完了結果

- `KifuwarabeGo2026.StationeryUI.dll` の単体ビルド成功。警告0・エラー0。
- ソリューション11プロジェクトのDebugビルド成功。警告0・エラー0。
- Gui.CoreからStationeryUIへの一方向のプロジェクト参照を確認。
- StationeryUIにプロジェクト参照がなく、Gui.Coreを参照していないことを確認。
- 移植性スモーク `PASS`。
- Windowsプラットフォームサービスの非対話スモーク `PASS`。

## 実装上の補足

文房具UI、Canvas、仮想画面、文字描画とプラットフォーム抽象のソースは、物理的にも `KifuwarabeGo2026.StationeryUI` 配下へ移動した。
GUI専用の `GuiUpdateProgressDialog` だけは `KifuwarabeGo2026.GameOasis.Gui` 配下に残し、Gui.Core側でコンパイルする。

StickyNoteの現在画面は、文房具UIからGUIのHUDを参照せず、Gui.Core側からコールバックで注入する構成へ変更した。
