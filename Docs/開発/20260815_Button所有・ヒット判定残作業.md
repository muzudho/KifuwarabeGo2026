# Button 所有・ヒット判定の残作業

## 目的

描画は `Button` へ統一済みだが、固定操作部品の所有場所とヒット判定には互換 API が残っている。今後は画面単位で、UI を所有するクラスの `Button.Bounds` と `Button.IsHit` を直接使う構造へ寄せる。

## 残作業

- `TextInputDialog`、`MessageDialog`、Entry Profile 関連に残る `IsXxxHit` ラッパーを、呼び出し側の直接参照へ置き換える。
- 固定ボタンを `Rectangle XxxButtonBounds` だけで保持している箇所を棚卸しし、画面・ダイアログ・コンポーネントが `Button` を所有する形へ移す。
- 実行時に個数やラベルが変わる操作列は、固定フィールドへ無理に変えず `Button` のコレクションまたは動的 `DrawButton` を使う。
- パネル、チャート、行、テキスト、ツールチップなどのレイアウト領域は `Rectangle` のまま維持する。

## 確認

```powershell
rg -n --glob "*.cs" "ButtonBounds|Is[A-Za-z]+Hit" KifuwarabeGo2026.GameOasis.Gui
dotnet build KifuwarabeGo2026.slnx --no-restore
```

移行ごとに描画位置、有効状態、クリック判定が同じ `Button` を参照することを確認する。
