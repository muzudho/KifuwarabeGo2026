# Match分離後のGUI接続改善計画

作成日: 2026-08-01

## 目的

`KifuwarabeGo2026.Match` の分離完了後に残ったGUI側の接続作業を、Match本体の責務を増やさず段階的に進める。

## 作業候補

### GUI時計サービスを接続する

- GUIの時計サービスから、Matchの決定論的な時計更新APIへ確定値を渡す。
- 表示用の補間と、Matchが保持する正本の時計状態を区別する。
- 古いシーケンスや不正な残り時間をGUIでも適切に表示する。

### GUIとの二重状態を縮小する

- `GoAppSession` と `MatchSession` が重複して保持している対局状態を列挙する。
- Matchのスナップショットを正本にできる項目から、GUI側の書き込み経路を削る。
- リプレイ、盤面編集、CGOS観戦など、Matchを正本にしない画面状態は分離して残す。

### 結果合意画面を接続する

- 黒白の結果申告、不一致、再申告、対局再開、審判裁定を画面で表現する。
- 本人確認と審判権限は、ローカルGUIではなく将来のサーバー側責務として混入させない。

## 推奨順序

1. 二重状態を調査して正本を明記する。
2. GUI時計サービスを接続する。
3. 結果合意画面を接続する。

## 完了条件

- GUIとMatchのどちらが各状態の正本か文書またはコードから判断できる。
- 時計と結果合意の主要経路に回帰検査がある。
- MatchがMonoGame、Windows API、GTPプロセスへ依存していない。
