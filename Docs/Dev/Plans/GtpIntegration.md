# GTP 連携の残検証・改善

記録時点の状況は[現状説明](../CurrentState/GtpIntegration.md)を参照してください。着手前に残存箇所を再確認します。

## 残作業

- 黒・白のどちらで失敗したかを、画面上のエラー表示でも明確にする。
- 起動失敗、同期失敗、異常応答、長時間対局、キャンセルの回帰確認を厚くする。
- Human 対 Computer、Computer 対 Human、Computer 対 Computer で、着手同期、パス、投了、二連続パス、全プロセス終了を確認する。
- 外部エンジンごとの互換性は、実機検証したバージョンと証拠を [指定局面エンジン検証結果](../CurrentState/InitialPositionValidation.md) に記録する。

## 完了条件

- 片側のエンジン異常で盤面不一致のまま対局を続行しない。
- エラー表示とログから対象エンジン、送受信、失敗位置を判断できる。
- ソリューションのビルドと該当スモークテストが成功する。
