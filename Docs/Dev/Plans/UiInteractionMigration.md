# UI操作標準の導入・確認

[操作標準](../CurrentState/UiInteractionStandard.md)を新規・既存画面へ適用します。

## 導入・確認の手順

新しい編集画面を追加するときは、次を満たすことをレビュー項目にする。

1. 変更は保存まで下書きに留まり、`DISCARD` で元に戻る。
2. `SAVE & CLOSE` は保存成功時だけ閉じる。
3. 失敗時は編集内容を残し、理由を表示する。
4. 左に `DISCARD`、右に `SAVE & CLOSE` を配置し、ほかの編集画面と同じ見た目にする。

既存画面は、保存処理と画面を閉じる処理の対応を確認しながら、この標準へ順次移行する。
