# Installer公開・移行確認

2026-09-07の[実装結果](../CurrentState/Installer.md)に残る公開時の確認です。コード改名とローカル試験は実施済みです。

## 次回リリース時

1. 公開済みの版を確認し、今回の版番号を決める。
2. 正規Installerと互換Launcherの両ZIP・チェックサムを同時に用意する。同一内容のZIPと、新旧exe・dll・deps.json・runtimeconfig.jsonの互換入口を維持する。
3. 公開版での新規取得、旧更新クライアントからの更新、インストーラー自身の更新を確認する。
4. 公開済み旧ロビーからの管理画面起動、標準ショートカットのロビー起動、更新後の復帰を確認する。
5. 結果、対象版、未確認事項を現状文書へ記録する。

## 維持する互換性

設定キー・ファイル名、`Launcher/Current`、JSON Lines第1版は維持する。互換撤去時期は未確定であり、改名済みという理由だけで旧入口を削除しない。
