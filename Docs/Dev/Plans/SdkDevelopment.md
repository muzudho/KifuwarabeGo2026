# SDK・外部実装ガイドの整備計画

Protocol Sの[外部実装SDK](../SDK/PlaySpace外部実装SDK.md)と、以下の未整備ガイドを区別します。ガイドがプレースホルダーでも接続契約そのものが未実装とは限りません。

## ゲームマスターエンジン実装ガイド

* Protocol Mの状態遷移図と全命令一覧。
* 勝敗判定、通常終局、例外裁定の優先順位。
* 複数Game Master登録時の選択と排他制御。
* JSON Lines Host SDK、マニフェスト、最小サンプル。
* 言語非依存Schema、適合性ベクトル、監査ログ要件。
* 人間Game Master GUIと自動Game Masterの実装例。

[現行ガイド](../SDK/ゲームマスターエンジン実装ガイド.md)

## プレイヤーエンジン実装ガイド

* Protocol Pの状態遷移図。
* 全要求・応答・通知の一覧。
* JSON Lines Host SDKとマニフェスト形式。
* 最小サンプルプレイヤー。
* 言語非依存JSON Schemaと適合性ベクトル。
* 時間制御、取消し、並行要求、異常終了の規約。
* GTP、USI等をProtocol Pへ適合する例。

[現行ガイド](../SDK/プレイヤーエンジン実装ガイド.md)

## プレイルームGUI実装ガイド

* Protocol Gの状態遷移とメッセージ一覧。
* Play Room GUIマニフェストと探索方法。
* MonoGameを使う参照GUIと、別言語GUIの最小例。
* Match、Board Editor、Review、Watchの共通点と差分。
* 入力、描画、通知、切断、再接続の適合性試験。
* アクセシビリティ、ローカライズ、画面サイズの最低要件。

[現行ガイド](../SDK/プレイルームGUI実装ガイド.md)

## プレイルームエンジン実装ガイド

* ゲーム固有Schema設計ガイド。
* 終局結果とGame Master裁定の分担。
* 複数セッション、取消し、時間制御の規約。
* パッケージ配布、バージョン互換、ランチャー登録。
* GUIやプレイヤーを含む結合適合性試験。

[現行ガイド](../SDK/プレイルームエンジン実装ガイド.md)
