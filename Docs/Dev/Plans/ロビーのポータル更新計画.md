# ロビーのポータル更新計画

2026-09-09。利用者と合意した、ロビー入口をプレイルームのカタログ中心へ更新する計画です。

## 目的と画面構成

ロビーを開いたときに、利用できるプレイルームを大きな一覧から選べるようにします。従来のENTRY SETTINGS／FORMAL APPS／CASUAL APPS／GAME PLATFORMという列分類を入口から外します。

- 上部：アイコンと文字を併記した［エンジン登録］［エントリー登録］［設定］［インストーラーを更新］［インストーラーを起動］。参加準備と管理操作の間に余白を設けます。
- 中央：画面の主な面積を使う、2列×2段のカタログ。各カードにアイコン・名前・説明・［開く］を表示します。
- 下部：位置を固定した［前へ］［現在ページ / 全ページ］［次へ］。1ページしかない場合や端のページでは、移動できない方向を無効にします。

## 最初のカタログ

| 名前 | 説明・接続先 |
|---|---|
| 囲碁ローカルマッチ | GTP対応エンジンや人間で対局。既存Local Matchへ接続 |
| 囲碁オンラインマッチ（CGOS） | GTP対応エンジンをCGOSへ接続・観戦。既存Online Matchへ接続 |
| ポン抜き | 石を取る囲碁ゲーム。既存Provider選択へ接続 |
| コンピューター囲碁サンプル | 開発者向けリファレンス実装。従来Game Oasis内の通常囲碁へ直接接続 |

ゲームオアシスの中間選択ページをサンプル起動時に経由しません。ポン抜きのサンプルEngineと通常のポン抜き入口は区別し、今回のカタログには上記4項目を置きます。

## 実装方針

1. 名前・説明・意味上の起動先を持つカタログとページ状態をLobbyGuiに置きます。初期登録は組み込み4件とし、外部マニフェスト探索は別作業です。
2. 描画・ヒット判定で共通のレイアウトを使い、既存の表示スケーリングに対応します。アイコンは既存の描画プリミティブで描き、絵文字フォントへ依存しません。
3. ロビーの上部メニューを既存の登録・設定・更新・起動操作へ接続します。非表示になった旧位置が反応しないようにします。
4. ページ移動はクリックとPageUp／PageDownに対応し、モーダル表示中は操作しません。ページをまたいだクリックが別項目を誤起動しないよう、表示と選択で同じカタログを使います。
5. サンプルは登録された通常囲碁の型IDを指定して開始します。起動準備中・失敗時は既存の案内を使います。

## 完了条件と検証

- 上部5メニュー、4枚のカード、下部ページャーが重ならず、文字とアイコンが読めること。
- 4項目がそれぞれ意図した開始・選択画面へ進み、戻れること。
- 追加項目を使う自動試験で複数ページ、端の無効状態、表示項目と選択先の一致を確認すること。
- 既存の描画依存・入力境界の試験と全体Releaseビルドを実施すること。
- 実画面を確認し、確認できた操作と未確認事項を記録すること。

今回の範囲はロビー入口の更新です。各プレイルームの通信移行、対局ルール、リリース作業は含めません。

## 実施結果

2026-09-09：計画の実装を反映しました。実アプリ全体での操作確認は、以下のOS拒否により一部未完了です。

- Homeの列分類を、上部5メニュー・中央2列×2段カタログ・下部固定ページャーへ置き換えました。登録2メニューは左、設定とインストーラー操作は右に寄せています。
- ロボ顔・人影・歯車・更新・起動のアイコンは描画プリミティブで描き、文字を併記しました。カタログにはゲーム別アイコンと説明、同じ位置の［開く］を付けました。
- LobbyGuiがカタログとページ状態を所有し、表示と選択は同じページ投影を使います。初期4件では［1 / 1］と移動不可のページャーを表示します。
- Local Match、CGOS、Provider選択へ既存の入口を接続しました。サンプルは通常囲碁の型IDを直接指定し、中間のGame Oasis一覧を経由しません。
- 上部の設定・更新・起動は既存処理へ接続しました。Homeでは非表示の旧下部ボタンとBACKをヒット判定から外しました。
- PageUp／PageDownはHomeが操作可能な場合だけ受け付けます。モーダルやサンプル盤面の操作中にはページを変更しません。

### 検証結果

- 全体Releaseビルド：成功。最初は警告0・エラー0。最終ビルドはエラー0、NuGet脆弱性情報取得の通信失敗によるNU1900警告1件です。
- ポータル専用試験：PASS。4件の選択先、サンプルの直接起動Intent、6件時の2ページ目、空き枠の無反応、空カタログ、ページ端、子ページでのページ移動禁止、コントロールの包含・非重複を確認しました。
- Windows非対話試験：PASS。
- ポータルの実描画コードを使う確認用ホストで、通常ページと追加2件を含む2ページ目をPNGへ描画し、文字・アイコン・カード・ページャーの配置を確認しました。[通常ページ](../../../artifacts/lobby-portal-ui/portal-render.png)／[2ページ目](../../../artifacts/lobby-portal-ui/page-two.png)。補助ホストと画像はartifacts内のローカル検証用で、配布対象ではありません。起動処理・設定・通信を検証するホストではありません。
- 実Lobby起動は`LobbyEngine.JsonLines.dll`の読込みがSmart App Controlの`0x800711C7`で拒否されました。記録は`Logs/Gui/Errors/application-error-20260909-231418.log`です。
- 総合GUI移植性試験も既存`Reference.PlayRoomGui.Go.MonoGame.dll`が同じOSポリシーで拒否され、完走できていません。ポータル専用試験と区別します。セキュリティ設定は変更していません。
