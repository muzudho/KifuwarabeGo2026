# CGOS評価値チャート追加改善計画

作成日: 2026-08-01

## 目的

初回の評価値チャート実装後に残った検証事項と、独立して追加できる改善を管理する。

## 最初に確認すること

- CGOSの `score` と `winrate` が送信者視点か、常に黒視点かを実データと仕様で確認する。
- `score` が何目差を表すか、ルールやエンジンによる差異を確認する。
- 現在の自動Y軸拡張、棋譜レビュー、表示モード保存の実装状況を再確認し、実装済みの項目を重複して作らない。

## 改善候補

- 長手数の対局で、全体圧縮、直近N手、横スクロールのどれが読みやすいか比較する。
- 表示モードをアプリ終了後も保持する必要があるか決める。
- 棋譜レビューでライブ観戦と同じチャート操作を利用できるか確認し、不足分だけ追加する。

## 完了条件

- `score` と `winrate` の視点と意味が文書化され、黒白を逆に表示する危険がない。
- 採用した改善に回帰検査または手動確認項目がある。
- 見送った候補と理由が記録されている。
