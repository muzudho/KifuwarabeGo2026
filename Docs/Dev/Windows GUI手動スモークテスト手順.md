# Windows GUI手動スモークテスト手順

最終更新: 2026-07-29

## この確認の目的

CoreとWindowsプロジェクトを分割した後も、利用者が実際に見る画面とWindowsのダイアログが従来どおり動くことを確認します。

一度に全部行う必要はありません。ラウンドごとに確認し、異常があった時点で止めてください。

異常があった場合は、次を残すと調査しやすくなります。

- どのラウンドの何番で起きたか
- 画面に表示されたメッセージ
- 可能ならスクリーンショット
- GUIを終了した時刻

エラーログは `Logs/Gui/Errors/application-error-*.log`、操作ログは `Logs/Gui/gui-operation-*.log` にあります。

## ラウンドC：SGFの保存と読込

既存ファイルを上書きしないよう、テスト用の新しいファイル名を使います。

- [ ] `LOCAL GAME` で人間同士の短い対局を開始し、1手以上打って `RESIGN` する。
- [ ] 結果画面の `SGF OUTPUT` で保存ダイアログが開く。
- [ ] `smoke-test.sgf` などの新しい名前で保存できる。
- [ ] `BACK TO SETUP` を押す。
- [ ] `SGF INPUT` で読込ダイアログが開く。
- [ ] 先ほど保存したSGFを選ぶと棋譜を読み込める。
- [ ] 棋譜レビュー画面で手順を前後に移動できる。

テスト用SGFは、確認後に不要なら削除して構いません。

## ラウンドD：GTPエンジン設定

保存済み設定を変えないよう、編集画面では基本的に `CANCEL` または `BACK` を使います。

- [ ] `LOCAL GAME` の黒番または白番を `COMPUTER` にすると、エンジン選択ボタンが使える。
- [ ] エンジン選択画面を開き、一覧とプロパティが表示される。
- [ ] `ADD` または `EDIT` から設定画面を開ける。
- [ ] 実行ファイル欄の `REF` で `.exe` 選択ダイアログが開き、キャンセルできる。
- [ ] 作業フォルダー欄の `REF` でフォルダー選択ダイアログが開き、キャンセルできる。
- [ ] `GUI OPTIONS` を開ける場合、文字列の `EDIT` と数値の編集画面が開き、キャンセルできる。
- [ ] 各画面を保存せず閉じ、元のローカル対局設定へ戻れる。

## ラウンドE：CGOS画面

実サーバーへ接続する項目は、利用可能なテスト用アカウントがある場合だけ行います。資格情報をこの確認結果へ貼り付けないでください。

- [ ] タイトル画面から `CGOS` を押すと接続先選択画面が表示される。
- [ ] 接続先を選び、接続準備画面へ進める。
- [ ] 黒番・白番のエンジン選択画面を開いて戻れる。
- [ ] CGOS通信コンポーネントが見つからないという誤警告が出ない。
- [ ] 接続した場合、ログを開く、ログフォルダーを開く、ログを追尾する操作が動く。
- [ ] 接続した場合、切断後にCGOS通信プロセスが残らない。
- [ ] `BACK` でタイトル画面へ戻れる。
