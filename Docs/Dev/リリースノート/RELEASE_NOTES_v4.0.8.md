# Kifuwarabe Go 2026 v4.0.8

ランチャーを「インストーラー」に改名し、普段はデスクトップからロビーを直接開けるようにしました。

> [!IMPORTANT]
> 通常利用する方は **`KifuwarabeGo2026.Installer-v4.0.8-win-x64.zip`** をダウンロードしてください。

## ダウンロードと始め方

1. ZIPをすべて展開し、`KifuwarabeGo2026.Installer.exe` を起動します。
2. ［CHECK GUI + ENGINE UPDATES］でGUIとEngineを取得します。
3. ［CREATE LOBBY DESKTOP SHORTCUT］でデスクトップに［きふわらべの碁２０２６］を作成できます。
4. ［START LOBBY］またはデスクトップのショートカットからロビーを開きます。

展開したインストーラーのフォルダーは、ショートカット作成後も移動・削除せず保存してください。更新や削除が必要なときは、ロビーの［インストーラーを起動］から管理画面を開けます。

動作環境はWindows x64と.NET 8 Desktop Runtimeです。SDKやVisual Studioは不要です。`.zip.sha256` は検証用データなので、通常利用者が開く必要はありません。

## 主な変更

- ランチャーの名称をインストーラーへ変更しました。
- 標準デスクトップショートカットは、管理画面を経由せずロビーを起動します。
- ロビーのボタンを［インストーラーを起動］、インストーラーの起動ボタンを［START LOBBY］へ変更しました。
- インストーラー画面からもロビー用ショートカットを作成できます。
- インストーラーを開いたままでもロビーを起動でき、ロビーから既存の管理画面へ戻れます。
- 起動できるロビーが見つからない場合や管理処理中の場合は、復旧・再試行の案内を表示します。

## 以前の版を使っている方へ

- 設定と導入済みバージョンを引き続き利用できます。
- 旧更新クライアント向けに `KifuwarabeGo2026.Launcher-v4.0.8-win-x64.zip` も添付しています。Installer版と同じ内容で、新旧名のexeを同梱しています。
- 古い管理用ショートカットはそのまま使えます。ロビーを直接開く入口が必要な場合は、新しいインストーラーからショートカットを作成してください。
- GUI単独用には `GameOasis.Gui` ZIP、旧クライアントとの互換用には `Gui` ZIPを添付しています。Engine単独ZIPも継続します。

## 開発者向け

- InstallerGui、InstallerEngine、Platform、Presentation、JsonLines、Host、対応テストを改名しました。
- `--launch-lobby` を追加し、現在版が起動できない場合は直前版を試します。
- 更新・削除・起動・設定変更の競合をファイルロックで検出します。
- 既存の設定キー、保存場所、旧環境変数、JSON Lines第1版との互換性を維持します。
