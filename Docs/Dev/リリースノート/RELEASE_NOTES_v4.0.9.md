# Kifuwarabe Go 2026 v4.0.9

通常囲碁のローカルマッチを、ロビーと独立したプレイルームの公開通信で進める方式へ切り替えました。

> [!IMPORTANT]
> 通常利用する方は **`KifuwarabeGo2026.Installer-v4.0.9-win-x64.zip`** をダウンロードしてください。

## ダウンロードと始め方

1. ZIPをすべて展開し、`KifuwarabeGo2026.Installer.exe`を起動します。
2. ［CHECK GUI + ENGINE UPDATES］でGUIとEngineを取得します。
3. ［START LOBBY］または作成済みのデスクトップショートカットからロビーを開きます。

動作環境はWindows x64と.NET 8 Desktop Runtimeです。SDKやVisual Studioは不要です。`.zip.sha256`はファイル検証用です。

## 主な変更

- 通常囲碁のローカルマッチで、ロビーから別プロセスの囲碁プレイルームへ公開通信で接続します。
- 着手・取り・不正着手の拒否・パス・投了を対局進行側で処理します。連続パスは既存の中国式面積採点で終局します。
- GTPエンジンの参加に対応し、終局時はロビーへ勝者と理由を返します。
- 通信異常やキャンセル時の後始末と、異常終了後の再起動を整えました。
- ロビーの描画を分離し、共通画面部品を独立StationeryUIパッケージへ移しました。

## 以前の版を使っている方へ

- 既存設定とインストーラーからの更新経路を維持します。
- 旧更新クライアント向けの`Launcher` ZIPと`Gui` ZIP、新しい名前の`GameOasis.Gui` ZIP、Engine単独ZIPも添付しています。
- InstallerとLauncherのZIPは互換用の新旧exeを同梱します。

## 確認範囲

開発者によるローカルマッチの動作確認に加え、自動試験で入力処理・採点・異常終了・GTP対局を検証しました。公式の実ウィンドウでもGTP同士の連続パスから採点・正常終了まで確認しています。他の画面は引き続き試用・確認中です。

編集・レビュー・ポン抜き・CGOSをすべて新しい公開通信へ移した版ではありません。最小プレイルーム表示への時計・アゲハマ数・最終着手などの追加や、時間切れの自動裁定は今後の作業です。

## 開発者向け

- `Reference.MatchRunner.Go`がProtocol G/Sによる対局進行と、標準入出力の囲碁ウィンドウを接続します。
- プレイルームは`--stdio`で能力照会、起動、局面更新、入力イベント取得、完了・終了を処理します。
- 独立Pythonクライアント・ホストのサンプルと通信仕様を追加しました。
- 配布時に必要な進行役・通信DLLの検査と、発行Hostで対局を通すスモークを追加しました。
