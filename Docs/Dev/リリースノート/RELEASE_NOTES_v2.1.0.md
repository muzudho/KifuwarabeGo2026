# Kifuwarabe Go 2026 v2.1.0

CGOS観戦とローカル対局へ評価値チャートを追加し、不具合調査のための操作ログと、画面遷移・ウィンドウ操作の安全性を改善したマイナーリリースです。

## 主な変更

- CGOS観戦画面へ、地の評価値（Score）と勝率（Winrate）を重ねて表示する `POSITION TREND` チャートを追加
- Scoreを前面の黒白縦棒、Winrateを背面の黒白折れ線として表示
- 黒番と白番がそれぞれ報告した評価値を別系列として描画
- `SCORE`、`BOTH`、`WIN RATE` の表示切替に対応
- 同じ共通チャートをローカル対局中画面と対局結果画面でも使用
- 対局中から結果画面へ移った後も、対局全体の評価値履歴と表示モードを維持
- CGOSの評価値、読み筋、探索数を着手情報として保持し、SGFへ保存・再読込可能
- CGOSで新しい対局が付いた際、即座に画面遷移せずカウントダウン通知を表示
- 通知からすぐ観戦するか、自分で後から観戦画面へ移るかを選択可能
- CGOS観戦で着手音を再生し、短時間に着手が続いても音が不自然に重ならないよう調整
- 非アクティブウィンドウへの最初のクリックでは画面操作を実行せず、アプリをアクティブにするWindows標準の挙動へ変更
- 利用者の操作とアプリによる自動画面遷移を記録するGUI操作ログを追加
- GUIログとCGOSログを `Logs/Gui`、`Logs/Cgos` 以下へ整理
- タイトル画面右下の設定ボタンからアプリケーション設定画面を開けるように変更
- アプリケーション設定画面でログ保存先を設定し、ログを一覧から選んでエディターで開けるように変更
- 利用者の実設定を `%LOCALAPPDATA%\KifuwarabeGo2026` 以下へ保存し、リリースZIPには開発環境の設定を含めない構成へ変更
- GTPエンジン未設定時と、GUI自身をエンジンとして誤指定した場合の対局開始を防止
- トーナメント設定をアプリケーション設定ファイルへ統合し、CGF Open 2026の9路盤・19路盤設定をデフォルト登録
- 設定画面へアプリケーション設定ファイルとエンジン設定ファイルの保存場所表示・フォルダー表示ボタンを追加
- トーナメント設定の持ち時間を `時:分:秒` で、手数上限を整数で直接入力できるように変更
- 持ち時間の1秒単位、手数上限の1手単位の微調整ボタンを追加
- 結果画面の戻る操作を右上の `BACK TO SETUP` ボタンへ整理
