# 次回リリース向け変更（未公開）

## ユーザー向け

- ランチャーの名前を「インストーラー」に変更します。
- デスクトップに作る標準ショートカットから、ロビーを直接開けるようにします。
- ロビーのボタンを［インストーラーを起動］、インストーラーの起動ボタンを［START LOBBY］へ変更します。
- インストーラーにも、ロビー用デスクトップショートカットの作成ボタンを追加します。
- 旧Launcher名のexe・更新用ZIPは互換用に残し、既存の設定と導入済みバージョンを引き続き利用します。

## 開発者向け

- GUI・Engine・Platform・Presentation・JsonLines・Host・対応テストをInstaller名へ改名します。
- `--launch-lobby` は管理画面用の二重起動防止より先に処理し、現在版が起動できない場合は直前版を試します。
- 更新・削除・起動の競合をファイルロックで検出し、処理中の場合は再試行の案内を返します。
- 詳細な検査結果と残確認は[実装計画](../開発_作業計画/20260907_インストーラー改名とロビー起動導線変更計画.md)に記録します。
