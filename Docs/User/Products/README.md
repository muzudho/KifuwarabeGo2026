# どういうアプリ

［きふわらべの碁２０２６］は、コンピューター囲碁の思考エンジン同士を対局させられるアプリケーションです。人間同士の対局や、人間とコンピューターの対局にも対応しています。

コンピュータ囲碁フォーラムオープン２０２６への参加実績があり、インターネット上のCGOS（コンピューター囲碁対局サーバー）にも接続できます。

## できること

- **囲碁の対局** — 9路・13路・19路の盤で、人間対人間、人間対コンピューター、コンピューター対コンピューターの対局ができます。
- **思考エンジンの接続** — GTP（Go Text Protocol）に対応した外部思考エンジンを利用できます。同梱の `Kifuwarabe Random GTP` は、合法手をランダムに選ぶエンジンです。
- **対局の設定** — 大会ルールや思考エンジンの設定を追加・編集・複製・削除できます。大会ルール、思考エンジン、CGOS接続先は使いたい順に並べ替えられます。
- **棋譜と局面の確認** — SGF棋譜の読み込み、局面編集、棋譜レビューができます。`L` キーで `BOARD LENS` 表示を切り替えられます。
- **CGOSへの接続** — コンピューター囲碁対局サーバーに接続して対局できます。
- **インストーラーでの導入・更新** — GUIとEngineの導入・更新、インストール済みバージョンの確認・アンインストールができます。普段はデスクトップのショートカットからロビーを開き、管理するときはロビーの［インストーラーを起動］を使います。

## 利用するには

配布対象は Windows x64 です。プログラム開発用のSDKやVisual Studioは必要ありません。

[始め方](../Installation/README.md)に、必要な動作環境と、ダウンロードからアプリのウィンドウを開くまでの手順をまとめています。

ゲームや外部エンジンとの接続について詳しく知りたい方は、[公開ドキュメント](../../../PublicDocs/README.md)をご覧ください。
