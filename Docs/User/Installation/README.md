# 始め方

最新版をダウンロードして、［きふわらべの碁２０２６］のウィンドウを開くまでの手順です。

## 動作環境

- Windows x64
- .NET 8 Desktop Runtime
- ダウンロードと更新のためのインターネット接続

プログラム開発用のSDKやVisual Studioは必要ありません。現在、作者が動作確認している環境はWindowsだけです。

## 1. ランチャーをダウンロードする

[最新版のダウンロード（GitHubリリースページ）](https://github.com/muzudho/KifuwarabeGo2026/releases/latest)を開き、Assetsから `KifuwarabeGo2026.Launcher-v～-win-x64.zip` をダウンロードします。`～` の部分にはバージョン番号が入ります。

通常利用する場合は、このランチャーのZIPだけをダウンロードしてください。GUIとEngineは、起動したランチャーから取得します。

末尾が `.zip.sha256` のファイルは、ランチャーがダウンロード内容を検証するためのデータです。利用者がダウンロードしたり開いたりする必要はありません。GUI版・Engine版のZIPは、単独利用や互換運用が必要な方向けです。

## 2. ZIPを展開する

ダウンロードしたZIPを右クリックし、［すべて展開］で、保存しておきたいフォルダーへ中身をすべて展開します。

ZIPの中から直接起動せず、展開先のフォルダーを開いてください。

## 3. ランチャーを起動する

展開先にある `KifuwarabeGo2026.Launcher.exe` をダブルクリックします。

.NETのランタイムが必要という案内が表示された場合は、案内に従って .NET 8 Desktop Runtime の x64 版をインストールし、もう一度ランチャーを起動してください。

起動時にWindowsから確認画面が出た場合は、ダウンロード元がこのGitHubリポジトリのリリースページであることを確認してから操作してください。

## 4. GUIとEngineを取得する

ランチャーの［CHECK GUI + ENGINE UPDATES］を押し、取得が完了するまで待ちます。

GUIはアプリの画面、Engineは思考エンジンです。初回は両方を取得してください。

## 5. アプリのウィンドウを開く

ランチャーの［START］を押します。アプリのウィンドウが開けば、起動までの準備は完了です。

次回以降も `KifuwarabeGo2026.Launcher.exe` を起動し、［START］からアプリを開きます。必要に応じて、ランチャーからGUIとEngineの更新を確認できます。

## v3.10.0以前から更新する場合

v3.10.0の［最新バージョンへ更新］はGUI用ZIPだけを取得する旧方式のため、共通ランチャーへ自動移行できません。

このページの手順に沿って最新版のランチャーを手動でダウンロードし、別のフォルダーへすべて展開して起動してください。古いショートカットは、ランチャーへのショートカットに作り直します。

旧更新機能が保存した版は自動移行しません。必要な版はランチャーから再取得してください。

## 使わなくなったバージョンを削除する場合

ランチャーのインストール済みバージョン画面で、GUI、Engine、および旧更新機能が保存した版をアンインストールできます。現在使用中の版と、復旧用の直前版は、誤削除を防ぐためアンインストールできません。
