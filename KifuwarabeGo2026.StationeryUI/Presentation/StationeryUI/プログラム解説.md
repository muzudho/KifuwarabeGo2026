# Stationery UI のアプリ側描画境界

共通部品とその解説は [StationeryUI](https://github.com/muzudho/StationeryUI/blob/main/docs/control-guide.md) へ移しました。
このプロジェクトはパッケージを参照し、きふわらべ固有の描画と画面連携を保持します。

[KfwStationeryDrawingTools](KfwStationeryDrawingTools.cs) は共通の `StationeryDrawingTools` を拡張し、
碁石・対局結果などの描画と画面別の付箋配置を接続します。
[BackgroundRenderer](BackgroundRenderer.cs) と付箋、GTP 用テキストダイアログはアプリに残しています。
保存先やモーダル操作の仕様は [アプリ固有連携](アプリ固有連携.md) を参照してください。
