# StickyNote

`StickyNote` は `GoScreenRenderer` に依存しない独立コンポーネントです。配置後の Bounds、コネクター、見出し、本文、配色、行間を所有します。

描画には `StickyNoteDrawingCallbacks` を受け取ります。これにより SpriteBatch、フォント、日本語描画、仮想座標系はホスト側へ閉じ込められます。

`KfwStationeryDrawingTools.cs` は既存画面からの利用をつなぐ薄いアダプターだけを担当します。

対象を説明する案内付箋を、画面ごとに同じ見た目で描く共通部品です。

## 入力

- `kind` と `anchorBounds`: 付箋の種別と配置基準。`TryPlace(screen)` が画面別の位置と大きさを決める
- `connectorStart`: 接続元。接続先 `ConnectorEnd` は配置時に決まる
- `accent`: 線と左端帯の色
- `borderColor`: 付箋の枠線色
- `heading`: 見出し
- `bodyLines`: 本文の行列

## 描画順

1. 対象と付箋の間にアクセント色の線を描く。
2. 影、背景、枠、左端帯を描く。
3. 見出しを既定の大きさで描く。
4. 本文を行ごとに既定の大きさで描く。

本文を狭い横幅へ縮小して押し込まず、呼び出し側が適切に改行して付箋を縦へ伸ばします。これにより、どの案内でも読みやすい文字サイズを保ちます。

画面 ID と `StickyNotePlacementStrategies` による配置がきふわらべ固有なので、この部品と解説はアプリ側に残しています。
