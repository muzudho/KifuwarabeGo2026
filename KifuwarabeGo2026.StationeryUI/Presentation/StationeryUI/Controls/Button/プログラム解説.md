# Button のプログラム解説

`Button` は位置・サイズ、ラベル、ラベル倍率、有効状態を所有する UI コンポーネントです。

`IsHit` は有効状態を含めてマウス位置を判定し、`Draw` は描画コールバックでホストへ委譲します。`EDIT ENTRY PROFILE` の DISCARD と SAVE & CLOSE が利用します。

ラベルは常にボタンの水平・垂直中央へ配置します。`AutoExpandLabel` が有効な場合は、指定された `LabelScale` が小さく、ラベルの左右に余裕があるときだけ、ボタン高に応じた読みやすい大きさまで拡大します。長いラベルは領域内へ収まる大きさに制限されます。
