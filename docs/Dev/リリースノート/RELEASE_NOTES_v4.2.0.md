# Kifuwarabe Go 2026 v4.2.0

## ユーザー向けの変更

- ローカルマッチの設定画面を整理しました。別窓の対局盤で、対応エンジンから届く評価値を確認できます。対局の準備中はスピナーを表示し、開始ボタンの連打を防ぎます。
- エンジンオプションをエントリーごとに設定できます。思考エンジンが［外部管理］と宣言した項目には、実効値と、編集できない理由を表示するツールチップが付きます。
- WindowsのCGOS接続画面に、現在接続しているWi-Fiの名前を表示します。対局前に大会用の接続先を確認できます。
- 着石音の再生に失敗した場合もローカルマッチを継続できるようにしました。

## ダウンロード

- 初めて使う場合は **Installer版** のZIPを展開し、`KifuwarabeGo2026.Installer.exe` を起動してください。［CHECK GUI + ENGINE UPDATES］でGUIとEngineを取得し、［START LOBBY］でロビーを開けます。
- **GUI版** と **Engine版** は個別に配布します。動作環境はWindows x64と .NET 8 Desktop Runtimeです。
- 既存の更新クライアント向けの互換ZIPを含め、配布する各ZIPにSHA-256チェックサムが付きます。

## 開発者向けの変更

- GTPの定義に `externallyManaged` を指定できます。切替ラッパーは選択先の実効値をGUIに伝え、実際の対局に使うエンジンが外部管理と宣言した項目への書き込みを省きます。切替ラッパーはソースから利用できます。
- MonoGameの復元メッセージをUTF-8で読み取るようにし、日本語WindowsのVisual Studioで起きるビルドログの文字化けを修正しました。

詳細は [2026年11月の開発日誌](https://github.com/muzudho/KifuwarabeGo2026/blob/v4.2.0/docs/Dev/Log/2026/11.md) を参照してください。
