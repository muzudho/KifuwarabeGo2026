# Kifuwarabe Go 2026 v4.1.0

## ユーザー向けの変更

- CGOSで前局の終局図を表示して待っていると、次局の開始時にライブ盤面へ切り替わります。過去の手をレビューしている場合は、通知の［対局を見る］から次局を観戦できます。
- CGOS接続画面の［説明］欄に、思考エンジンが報告した稼働中の情報を表示します。系統切り替え用ラッパーを使う場合は、実際に起動した１系・２系・３系が表示されます。
- ロビーの入口を、囲碁ローカルマッチ・CGOS・ポン抜き・コンピューター囲碁サンプルから選べるカタログに更新しました。

## ダウンロード

- 初めて使う場合は **Installer版** のZIPを展開し、`KifuwarabeGo2026.Installer.exe` を起動してください。［CHECK GUI + ENGINE UPDATES］でGUIとEngineを取得し、［START LOBBY］でロビーを開けます。
- **GUI版** と **Engine版** は個別に配布します。両方を単体で使う場合は、両方のZIPが必要です。動作環境はWindows x64と .NET 8 Desktop Runtimeです。
- 旧名のLauncher版とGui版も、既存の更新クライアント向けに提供します。各ZIPにはSHA-256チェックサムを添付します。

## 開発者向けの変更

- CGOSの観戦状態と終局レビューの判定を分け、次局の通知とライブ盤面への遷移を修正しました。
- CGOS通信ホストが思考エンジンの説明を通知し、GUIはプレイヤーごとに表示します。３系統を次局から切り替えるGTPラッパーはソースから利用できます。
- 開発文書のフォルダー名を `docs` に統一し、文書リンクとリリース手順の参照先を更新しました。

詳細は[2026年11月の開発日誌](https://github.com/muzudho/KifuwarabeGo2026/blob/v4.1.0/docs/Dev/Log/2026/11.md)を参照してください。
