# Strong Analyzer

`StrongAnalyzer` は Strong Lens の評価計算を共有するための API です。GUI は数値を描画し、エンジンは同じ数値を着手評価に使えます。

## 評価式

```text
Value = 自連の面積 − 隣接する全相手連の面積
```

面積は連に含まれる石の数です。空点の連と同色の連は相手連として数えません。

## API

```csharp
var analysis = StrongAnalyzer.Analyze(renParse, renNumber);
var value = analysis.Value;
var touchesOpponent = analysis.TouchesOpponent;
```

`StrongAnalysis` は、自連面積・隣接相手連の面積合計・接触した相手連数も返します。

## 利用側の役割

- `KifuwarabeGo2026.GameOasis.Gui`: `Value` を Strong Lens として盤上へ描画する。
- `KifuwarabeGo2026.Engine`: `Value` と `TouchesOpponent` をポン抜きの接触優先度に使う。

描画、色、MonoGame の型、乱数による着手選択は Shared には置きません。
