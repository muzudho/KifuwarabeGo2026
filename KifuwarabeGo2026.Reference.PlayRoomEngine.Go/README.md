# KifuwarabeGo2026.Reference.PlayRoomEngine.Go

通常囲碁をProtocol Sへ接続する公式参照実装です。`GameOasis.Contracts`だけを参照し、現行GUI、`Match`、`Shared`、コンシェルジュの具象実装には依存しません。

v1は9路、13路、19路、中国式面積計算、コミ、明示的な初期配置、手番指定、石の捕獲、自殺手禁止、単純コウ、盤面の位置的スーパーコウ、パス、二連続パスによる計算終局、投了を扱います。二連続パス時は盤上の石をそのまま生き石として機械的に面積計算するため、死石除去や双方の合意が必要な対局はゲームマスター裁定を併用します。

時計、参加者認証、停止、再開、運営裁定はプレイスペースの外側にあるゲームコンシェルジュの責務です。日本ルールの死活確認と地の合意はv1には含めません。
