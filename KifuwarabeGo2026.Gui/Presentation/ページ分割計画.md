# GoScreenRenderer 分割計画

最終更新: 2026-08-13

## 目的

`GoScreenRenderer` は、SpriteBatch・フォント・基本図形描画を提供するレンダリングホストに寄せる。
各ページおよび再利用可能な UI は、位置・サイズ・構成部品・当たり判定・画面固有の描画手順を所有する独立クラスにする。

- 単独の画面は `Presentation/Pages/<画面名>/` に置く。
- 複数の画面から呼ばれる画面／パネルは `Presentation/Shared/<画面名>/` に置く。
- 汎用コントロールは `Presentation/StationeryUI/Controls/<部品名>/` に置く。
- `GoScreenRenderer` 依存の描画処理、文字幅計算、座標変換は `...DrawingCallbacks` として渡す。
- 切り出し後に残す partial は、コンポーネントへコールバックを渡す Host のみに限定する。

## 1 件ごとの完了条件

1. ページ／部品本体が `GoScreenRenderer` を参照しない独立クラスになっている。
2. レイアウト、構成部品、当たり判定は独立クラスが所有している。
3. 描画・文字計測などのレンダラー依存は callback record 経由で渡している。
4. 呼び出し元が独立コンポーネントのプロパティ／メソッドを利用している。
5. `dotnet build KifuwarabeGo2026.Gui/KifuwarabeGo2026.Gui.Core.csproj --no-restore` が警告・エラーなしで成功する。
