# Nobi Lens アルゴリズム

Nobi Lens は、現在の局面だけを使い、手番の自連から伸びられる候補点を表示する Board Lens です。

実装は [NobiLens.cs](./NobiLens.cs) にあります。候補点として着手できるかどうかの最終判定は `GoAppSession.IsNobiCandidate` が行います。

## 処理の流れ

```text
手番の自連をすべて取得
  ↓
各自連の全石から上下左右の隣点を調べる
  ↓
空点・自分の眼ではない・コウではない点だけを候補にする
  ↓
自連から候補へ足を描き、候補点へ丸印を描く
```

## 候補にする条件

自連の石に上下左右で接する点について、次のすべてを満たすとノビ候補です。

- 盤内である。
- 空点である。
- 手番の石にとっての自分の眼ではない。
- 直前のコウ点ではない。
- スーパーコウとなる点ではない。

この判定により、単に隣接する空点ではなく、現在の局面でノビとして検討できる点を表示します。

## 描画

- 足は手番の石と同じ色で描く。
- 候補点の外周は手番の石と同じ色の丸にする。
- 候補点の内側はエメラルドグリーンの丸にする。
- 複数の自石から同じ候補点へ足が伸びる場合でも、候補点の丸印は一つだけ描く。

## 改造の入口

| 変更したいこと | 主な変更先 |
| --- | --- |
| 候補に含める・除外する条件 | `GoAppSession.IsNobiCandidate` |
| 調べる方向（現在は上下左右） | `NobiLens.cs` の `AddCandidate` 呼び出し |
| 足・丸印の色や太さ | `NobiLens.cs` の描画パラメーター |
| 眼・コウ・スーパーコウの判定 | `GoBoard.IsEyeFor`、`KoPoint`、`IsSuperKoPoint` |
