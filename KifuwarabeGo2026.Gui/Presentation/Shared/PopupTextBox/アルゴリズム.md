# ポップアップテキストボックスのアルゴリズム

## 用途

GTP エンジンの GUI オプションのうち、`string` 型の値をゲーム内で編集するモーダル入力画面である。
OS のネイティブ入力ダイアログは使わず、数値ポップアップと同じ描画・操作モデルを採用する。

## 処理の流れ

1. `string` 型オプションの EDIT を押すと、現在の下書き値で `TextBoxController` を初期化して開く。
2. 共通テキストボックスが文字入力、選択、コピー・切り取り・貼り付け、undo/redo、キーリピートを処理する。
3. 入力欄のクリック・ドラッグは、文字幅から変換したキャレット位置をコントローラーへ渡して選択を更新する。
4. Enter または OK ではテキストを下書きへ保存する。Escape または CANCEL では保存せず閉じる。

## 表示と制限

`PopupTextBox.cs` は暗幕付きの大きな入力欄、選択ハイライト、キャレット、OK/CANCEL を描画する。
最大文字数は `GtpEngineGuiOptions.MaximumTextLength`（現在 10,000）で、上限に達した追加入力時はメッセージを表示する。

値の妥当性は文字列型オプションに固有のルールがある場合に、呼び出し側またはエンジン側で扱う。現在の `EngineTag` は文字列型操作のデモ用プロパティであり、追加の内容検証は行わない。
