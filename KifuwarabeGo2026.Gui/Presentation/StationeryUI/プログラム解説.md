# Stationery UI の描画境界

`StationeryDrawingContext` は、`GoScreenRenderer` と文房具UIを分離する共通描画APIです。

- `GoScreenRenderer` は生成時に基本描画メソッドをcontextへ渡します。
- Button、Headline、Underlineなどの文房具UIはrendererを受け取らず、contextだけを受け取ります。
- 文房具UIに新しい基本描画機能が必要になった場合は、個別の描画インターフェースを増やさず `StationeryDrawingContext` を調整します。
- `GoScreenRenderer` は文房具UI用の描画インターフェースを実装しません。

現在の共通APIは、矩形塗り、角丸矩形塗り、矩形枠、直線、通常文字、領域内へ収める文字、中央へ収める文字、回転中央文字の描画です。
