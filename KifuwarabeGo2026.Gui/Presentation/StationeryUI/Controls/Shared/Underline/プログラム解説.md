# UnderlineRenderer のプログラム解説

`UnderlineRenderer` は、文房具 UI のアンダーライン形状を組み立てる描画専用の static クラスです。

- `DrawRounded` は、内容領域の下端を基準に丸み付きの下線領域を計算します。
- `DrawLine` は、線分アンダーラインの描画を委譲します。
- どちらも実際の描画はコールバックへ渡すため、`GoScreenRenderer`、SpriteBatch、フォント、仮想座標系へ依存しません。

Link Underline、テキスト入力用の Underline、罫線状の複数行 Underline は、この共通形状を使えます。
