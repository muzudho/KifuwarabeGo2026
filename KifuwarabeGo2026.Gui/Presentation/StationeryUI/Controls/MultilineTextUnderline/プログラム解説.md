# PopupTextArea

## 操作名

- `APPLY` は編集中のコメントを SGF の `C[]` 値へ反映する操作であり、ファイル保存ではない。
- `CANCEL` は編集中の変更を破棄してポップアップを閉じる。
- `Enter` は改行、`Ctrl+Enter` は `APPLY`、`Escape` は `CANCEL`。

SGF コメントなどの複数行テキストを編集するモーダル共通部品です。

- Enter は実改行 `\n` を入力する。
- Ctrl+Enter は保存、Escape は取消。
- Windows の IME Composition は黄色で表示する。
- 背景入力はモーダル中に受け付けない。
- 本文は Windows 文字ラスタライザーで描画し、日本語を含めて表示する。
- `LineHeight` と `BaselineOffset` は本文と同じフォント設定の実測値を所有する。
- 罫線は最初の文字ベースラインから実測行高ずつ進めて描き、行を下っても本文との間隔がずれない。
