# Link Underline

クリックで非同期アクションを開始する、文房具 UI のアンダーライン部品です。

- 実行中は二重起動を受け付けません。
- 開始から 0.1 秒を超えても処理中なら、リンク右端にスピナーを表示します。
- `Cancel()` は `CancellationToken` でアクションへ中断を要求します。アクションが完了するまでは再実行できません。
- 中断要求後は、アクションが正常終了した場合も成功扱いにはせず、`中断しました。状態が完全に更新されていない可能性があります。` と表示します。

`LinkUnderlineRenderer` は `GoScreenRenderer` に依存しない、描画専用の static クラスです。`Draw` に渡すコールバックは2つだけです。

- `drawUnderline`: 日本語ラベルと下線を描画する処理
- `drawSpinner`: 指定座標にスピナーを描画する処理

ホストが持つフォント、SpriteBatch、仮想座標変換はこの2つのコールバック内で使います。

同期的に画面遷移・選択を行う既存リンクには、スピナーを持たない `Draw(bounds, label, hovered, drawUnderline)` を使えます。`PROVIDER` と GTP オプションの値表示は、この入口を利用しています。

## 使用例

```csharp
if (LinkUnderlineHitTest.IsHit(bounds, mousePoint))
    controller.TryStart(token => LoadAsync(token), nowSeconds);

controller.Update();
LinkUnderlineRenderer.Draw(
    bounds, "PROVIDER", mousePoint, controller, nowSeconds,
    drawUnderline,
    drawSpinner);
```

画面を閉じる際には `Cancel()` を呼び、中断完了後にエラー状態を描画してください。
