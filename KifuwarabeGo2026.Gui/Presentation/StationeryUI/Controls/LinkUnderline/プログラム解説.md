# Link Underline

クリックで非同期アクションを開始する、文房具 UI のアンダーライン部品です。

- 実行中は二重起動を受け付けません。
- 開始から 0.1 秒を超えても処理中なら、リンク右端にスピナーを表示します。
- `Cancel()` は `CancellationToken` でアクションへ中断を要求します。アクションが完了するまでは再実行できません。
- 中断要求後は、アクションが正常終了した場合も成功扱いにはせず、`中断しました。状態が完全に更新されていない可能性があります。` と表示します。

`LinkUnderline` は `IUnderline` を所有し、状態に応じた色で描画する UI コンポーネントです。`GoScreenRenderer` には依存しません。実際の下線描画は `IUnderlineDrawingSurface` へ委譲します。

- `drawText`: 日本語ラベルを描画する処理
- `drawSpinner`: 指定座標にスピナーを描画する処理

ホストが持つフォント、SpriteBatch、仮想座標変換は `drawText`、`drawSpinner`、`IUnderlineDrawingSurface` 側で扱います。

同期的に画面遷移・選択を行う既存リンクには、スピナーを持たない `Draw(bounds, hovered, surface)` を使えます。`PROVIDER` と GTP オプションの値表示は、この入口を利用しています。

## 使用例

```csharp
if (LinkUnderlineHitTest.IsHit(bounds, mousePoint))
    controller.TryStart(token => LoadAsync(token), nowSeconds);

controller.Update();
var linkUnderline = new LinkUnderline(new RoundUnderline());
linkUnderline.Draw(
    bounds, "PROVIDER", mousePoint, controller, nowSeconds,
    drawText, drawSpinner, underlineDrawingSurface);
```

画面を閉じる際には `Cancel()` を呼び、中断完了後にエラー状態を描画してください。
