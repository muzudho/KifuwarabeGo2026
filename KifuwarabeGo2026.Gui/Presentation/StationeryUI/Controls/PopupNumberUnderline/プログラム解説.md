# Popup Number Underline のプログラム解説

## 目的

GTP エンジンの GUI オプションのうち、`spin`（整数）型の値を編集するためのモーダル入力画面である。
現在は `GoScreenRenderer` の部分クラスと `Game1` の協調で実装しており、
文字編集そのものは共通部品の `TextBoxController` を再利用する。

```text
spin 型オプションの EDIT
          ↓
Game1.EditGtpEngineSpinOption
          ↓
TextBoxController.Begin(現在値)
          ↓
キーボード・文字入力・OK/CANCEL
          ↓
整数形式と範囲を検証
          ↓
オプションの下書きへ反映、または取消し
```

## コードの責務

| 場所 | 責務 |
| --- | --- |
| `PopupNumberUnderline.cs` | Link Underline 遷移後のポップアップ、入力欄、キャレット、選択範囲、メッセージ、OK/CANCEL ボタンの描画とヒット判定 |
| `Game1` | 開閉、キーボード・マウス・文字入力の振り分け、整数値と範囲の検証、保存 |
| `TextBoxController` | 文字列、キャレット、選択、クリップボード、undo/redo、キーリピート |
| `GtpEngineGuiOptionSpec` | 対象オプションのラベル、最小値、最大値 |

ポップアップ専用の編集状態は `Game1` が持つ。

- `_activeGtpEngineIntegerOption`: 編集対象。`null` ならポップアップは閉じている。
- `_gtpEngineIntegerOptionTextBox`: 最大 11 文字の共通テキストボックス。
- `_previousGtpEngineIntegerKeyboard`: キーの押下開始とリピートを判定する前フレーム状態。
- `_gtpEngineIntegerInputMessage`: 範囲表示・入力エラーを表示するメッセージ。

## 開く処理

`EditGtpEngineSpinOption` が次を行う。

1. 対象の `spin` オプションをアクティブにする。
2. オプションの下書き値でテキストボックスを初期化する。
3. 現在のキーボード状態を保存して、開いた瞬間のキーを誤入力として扱わないようにする。
4. `RANGE min .. max` をメッセージ欄に表示する。最小値または最大値が未指定なら `Int32` の最小値・最大値を使う。

描画はアクティブなオプションがある間だけ行う。半透明の背景で背後を覆い、入力欄、キャレット、メッセージ、CANCEL と OK を描くため、操作はモーダルになる。

## 入力処理

ポップアップを開いている間、通常画面より先に次の処理を行う。

- `TextInput` では数字、およびキャレットが先頭にある場合の `-` だけを受け付ける。
- `HandleKeyboard` では共通テキストボックスの操作を使用する。キャレット移動、選択、コピー・切り取り・貼り付け、Backspace、Delete、Ctrl+Z、Ctrl+Y、キーリピートが使える。
- 貼り付けにも `数字または -` のフィルターを適用する。これは文字種の制限であり、`--1` のような整数として不正な形は確定時に検証する。
- Enter は OK と同じ確定処理、Escape は CANCEL と同じ取消し処理を行う。
- マウスの OK/CANCEL ボタンも同じ確定・取消し処理を呼ぶ。
- 入力欄のクリックでキャレットを置き、ドラッグで文字列を選択する。Shift+クリックでは既存の選択を拡張し、ダブルクリックでは全文選択する。

クリック位置からのキャレット位置は、`PopupNumberUnderline.cs` が入力欄内の文字幅を計測して求める。
マウス操作は `BeginMouseSelection` / `UpdateMouseSelection` を通じて共通 `TextBoxController` へ渡すため、
選択した文字列はキーボード入力、切り取り、削除、貼り付けで共通テキストボックスと同様に扱える。

## 確定と検証

OK または Enter で `CommitGtpEngineIntegerInput` を実行する。

1. `int.TryParse` で符号付き 32 ビット整数に変換する。失敗時は `ENTER A VALID INTEGER` を表示し、ポップアップを開いたままにする。
2. オプションの最小値・最大値と比較する。範囲外なら `OUT OF RANGE min .. max` を表示し、開いたままにする。
3. 有効なら正規化した `value.ToString()` をオプションの下書きへ保存する。
4. アプリ提供者のゲーム設定ダイアログを表示中なら、設定評価を予約する。
5. 取消し処理を呼び、アクティブな対象、テキストボックス状態、メッセージを消去して閉じる。

CANCEL または Escape は下書き値を変更せず、同じ取消し処理で閉じる。

## 描画上の注意

`PopupNumberUnderline.cs` の座標は仮想画面座標で定義しており、実際のウィンドウ座標は
`VirtualScreen.ToVirtualPoint` と変換行列で扱う。キャレット X 座標は、文字列先頭から
`CaretIndex` までをフォント計測して求め、入力欄の右端を超えない位置に制限して描画する。
