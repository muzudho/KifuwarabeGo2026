## 文書の読み方

各仕様では、`必須`、`任意`、`禁止`を要求の強さを示す言葉として使用します。

- `必須`は、相互運用のために実装しなければならない要件です。
- `任意`は、実装しなくても互換性を失わない機能です。
- `禁止`は、相互運用を壊すため行ってはならない動作です。
