# Ponnuki実装リファレンス

> 対応バージョン：KifuwarabeGo2026 v3.1.0
> 記事の更新日：2026-08-02

`ponnuki`は、ポン抜きゲームを実現するGo Appの共通アプリIDです。Go Appsへ対応するエンジン作者が参照できる、最小で具体的な実装例として整備します。

## 実装する役割を選ぶ

- [Provider](Provider.md) — 初期局面を生成し、着手、アゲハマ、終局、勝者を監視する
- [Player](Player.md) — 与えられた初期局面から合法な着手を生成する

ProviderとPlayerは独立した役割です。一つのエンジンが両方へ対応することは必須ではありません。

両方に共通するアプリID、GTP応答、能力確認については、[Go Apps共通規約](../共通規約.md)を参照してください。

## アプリ識別子

```text
app-id: ponnuki
roles:  player, provider
```

アプリIDにエンジン名や作者名を付けません。同じ`ponnuki`を名乗る実装は、ここに記載するプロトコルとの相互運用性を維持してください。
