# 最小のPlayエンジンを作る

> 対応バージョン：KifuwarabeGo2026 v3.1.0<br>
> 記事の更新日：2026-08-02

## 1. 必須コマンド

［きふわらべの碁２０２６］で初期配置のない通常対局を行う最小エンジンは、次のコマンドへ対応してください。

```text
protocol_version
name
version
known_command
list_commands
boardsize
clear_board
komi
play
genmove
quit
```

`protocol_version`、`name`、`version`はエンジンの自己説明に使います。対局の中心となるコマンドは`boardsize`、`clear_board`、`komi`、`play`、`genmove`です。

> **引用用要件：Playの最小コマンド**  
> PlayのPlayerエンジンは、盤サイズとコミを受け取り、盤を初期化し、相手の着手を適用し、自分の合法手を生成できなければならない。対応コマンドは`known_command`と`list_commands`で正しく公開する。

## 2. 最小の入出力確認

エンジンを単体起動し、標準入力へ次のコマンドを一行ずつ送ります。

```text
protocol_version
name
version
known_command genmove
list_commands
boardsize 9
komi 6.5
clear_board
play black D4
genmove white
quit
```

応答例です。`genmove`の着手は局面によって変わって構いません。

```text
= 2

= My Go Engine

= 1.0.0

= true

= protocol_version
name
version
known_command
list_commands
boardsize
clear_board
komi
play
genmove
quit

=

=

=

=

= E5

=

```

各応答の末尾には空行が必要です。エンジンは`genmove white`で返した`E5`を、自分の内部盤にも白石として反映します。

## 3. GUIへ登録する

［きふわらべの碁２０２６］のエンジン設定で、少なくとも次の項目を指定します。

| 項目 | 内容 |
|---|---|
| 表示名 | GUIで識別する任意の名前 |
| 実行ファイル | 起動するGTPエンジンのパス |
| 作業ディレクトリー | エンジンがファイルを探す基準ディレクトリー |
| 起動引数 | 必要な場合だけ指定する引数 |

エンジンを黒または白のComputer Playerとして選択し、対局を開始します。GUIはエンジンを子プロセスとして起動し、標準入力と標準出力で通信します。コンソール入力、ダイアログ、確認画面などの対話操作をエンジン側から要求してはいけません。

## 4. 動かないときの確認

- 標準出力の先頭が`=`または`?`になっているか。
- 応答の最後に空行を出しているか。
- デバッグ文字列を標準出力へ出していないか。
- 標準エラーへ警告やログを出していないか。
- `genmove`がGTP頂点または`pass`だけを返しているか。
- GUIから送られる色`black`と`white`を受理できるか。
- 9路、13路、19路のうち、選択した盤サイズを受理できるか。
- 各コマンドへ10秒以内に応答しているか。

ログが必要な場合は、標準入力、標準出力、標準エラーを避け、エンジン専用のログファイルへ書き出してください。
