# Play実装リファレンス

> 対応バージョン：KifuwarabeGo2026 v3.1.0
> 記事の更新日：2026-08-02

`Play`は、［きふわらべの碁２０２６］で通常の囲碁対局を行うGo Appです。従来の画面名`Go Play`とGo Appsの`Play`は同じものを指します。

このフォルダーだけを読めば、外部のGTP仕様書を探さなくても、［きふわらべの碁２０２６］から起動して対局できるエンジンを実装できることを目標とします。

## アプリ識別子

```text
app-id: play
role:   player
```

## 実装する順序

1. [最小エンジン](最小エンジン.md) — 最初に対応するコマンドと登録確認
2. [GTPコマンド](GTPコマンド.md) — 入出力形式と各コマンドの意味
3. [対局シーケンス](対局シーケンス.md) — GUIが送る実際の順序と盤状態の同期
4. [エンジンオプション](エンジンオプション.md) — GUIから設定を変更できる任意拡張

## 対応範囲

最小実装では、9路、13路、19路の互先対局に必要なGTPコマンドへ対応します。Playerは黒番にも白番にも割り当てられるため、色を固定してはいけません。

初期配置のない通常対局には標準的なGTPコマンドだけで参加できます。置き石や編集された初期局面へ対応する場合は、追加の局面設定能力が必要です。
