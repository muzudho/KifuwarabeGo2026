# Playのエンジンオプション

エンジンオプションは任意機能です。対応しない標準GTPエンジンもPlayで利用できます。

対応すると、利用者は［きふわらべの碁２０２６］のエンジン設定画面から、思考方式、乱数シード、ファイルパスなどを変更できます。

## 1. コマンド

```text
kfw-options
kfw-get-option <id>
kfw-set-option <id> [value]
```

対応する場合は、三つのコマンドを`known_command`と`list_commands`で公開します。

GUIは保存済みの値がある場合、エンジン起動直後に概ね次の順序で処理します。

```text
known_command kfw-options
kfw-options
kfw-set-option <id> <value>
```

その後、`boardsize`、`komi`、`clear_board`による対局初期化へ進みます。

## 2. 定義JSON

`kfw-options`は、GTP成功応答の本文へバージョン1のJSONを返します。

```json
{
  "version": 1,
  "options": [
    {
      "id": "Threads",
      "label": "Threads",
      "type": "spin",
      "default": "1",
      "value": "1",
      "min": 1,
      "max": 64,
      "vars": []
    }
  ]
}
```

| フィールド | 意味 |
|---|---|
| `id` | `get`と`set`で使用する一意な識別子 |
| `label` | GUIへ表示する名前 |
| `type` | 値の型 |
| `default` | 既定値を表す文字列 |
| `value` | 起動直後の現在値を表す文字列 |
| `min` | `spin`の最小整数。それ以外では`null`にできる |
| `max` | `spin`の最大整数。それ以外では`null`にできる |
| `vars` | `combo`の候補。それ以外では空配列にできる |

## 3. 対応する型

| 型 | 設定値 |
|---|---|
| `check` | `true`または`false` |
| `spin` | `min`以上`max`以下の整数 |
| `combo` | `vars`に含まれる文字列 |
| `string` | 文字列 |
| `filename` | ファイルパス |
| `button` | 値を持たない一回実行操作 |

`string`と`filename`は最大10,000文字です。`button`は`kfw-set-option <id>`のように値なしで送られます。

## 4. 値の取得と変更

```text
> kfw-get-option Threads
= 1

> kfw-set-option Threads 4
=

> kfw-get-option Threads
= 4
```

不明なID、型に合わない値、範囲外の値にはGTPエラーを返します。不正な値を黙って採用してはいけません。

オプション値の永続化はGUIのエンジンプロファイルが担当します。エンジンは、起動後に受け取った`kfw-set-option`をそのプロセスへ反映できれば利用できます。

> **引用用要件：エンジンオプション**  
> `kfw-options`は型と範囲を含む定義を返し、`kfw-set-option`は定義に適合しない値をGTPエラーとして拒否しなければならない。GUIは保存値を検証してからエンジン起動時に適用する。
