# Playの対局シーケンス

## 1. 通常の開始

初期配置のない対局では、GUIは各Computer Playerエンジンを別プロセスとして起動します。保存されたエンジンオプションがあれば先に適用し、その後で対局盤を初期化します。

基本の初期化順序は次のとおりです。

```text
boardsize 19
komi 6.5
clear_board
```

盤サイズとコミは対局設定によって変わります。各コマンドが成功してから次のコマンドへ進みます。

## 2. Computer対Human

Computerが黒の場合の例です。

```text
GUI -> Engine: genmove black
Engine -> GUI: = D4

GUI -> Engine: play white Q16
Engine -> GUI: =

GUI -> Engine: genmove black
Engine -> GUI: = C3
```

`genmove`で返した自分の手はエンジン自身が内部盤へ適用します。Humanの手はGUIが`play`で通知します。

## 3. Computer対Computer

黒エンジンと白エンジンは別々の盤状態を持ちます。GUIは着手を生成したエンジン以外へ、その着手を`play`で同期します。

```text
GUI -> Black Engine: genmove black
Black Engine -> GUI: = D4
GUI -> White Engine: play black D4
White Engine -> GUI: =

GUI -> White Engine: genmove white
White Engine -> GUI: = Q16
GUI -> Black Engine: play white Q16
Black Engine -> GUI: =
```

## 4. パス

`genmove`は`pass`を返せます。相手エンジンが存在する場合、GUIは`play black pass`のように同期します。終局済みであることを表す独自文字列を返してはいけません。

## 5. 初期配置がある対局

置き石や編集局面がある場合、GUIはエンジンの能力を`known_command`と`list_commands`で調べ、利用できる局面設定方法を選びます。

最も広い局面を安全に受け取るには、次の原子的指定局面コマンド一式へ対応してください。

```text
kfw-begin-position
kfw-add-black <vertex>
kfw-add-white <vertex>
kfw-set-to-play <black|white>
kfw-commit-position
kfw-abort-position
```

詳しい原子性と各コマンドの動作は、同じPlayer向け仕様である[Ponnuki Playerの指定局面](../Ponnuki/Player.md#2-指定局面への対応)を参照してください。

原子的指定局面に対応しないエンジンについては、GUIが互換方式を試せる場合があります。ただし、通常の着手順では再現できない局面もあるため、すべての初期配置に対応できるとは限りません。

## 6. 終了

対局終了やキャンセルでエンジンが不要になると、GUIは`quit`を送ります。エンジンは成功応答を返して自発的に終了してください。終了しない場合、GUIがプロセスを強制終了することがあります。

## 7. 応答時間

ローカルPlayでは、GUIは各GTPコマンドの応答を現在10秒待ちます。`genmove`を含め、10秒以内に完全な応答と末尾の空行を返してください。

標準時間管理コマンドは、現在の最小Playシーケンスには含まれません。思考時間は起動引数、設定ファイル、または[エンジンオプション](エンジンオプション.md)で制御します。
