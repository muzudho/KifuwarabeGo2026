# 続きはここから

## 次の優先作業

Windows 固有処理を差し替え可能にする計画を作成した。

- 詳細: [開発/クロスプラットフォーム対応のためのWindows依存分離計画.md](./開発/クロスプラットフォーム対応のためのWindows依存分離計画.md)
- Windows 実装プロジェクト名の第一候補は `KifuwarabeGo2026.Gui.Windows`。
- 別プロジェクトへ移した後も `AssemblyName=KifuwarabeGo2026.Gui` とし、実行ファイル名は `KifuwarabeGo2026.Gui.exe` を維持する。
- `IClipboardService` と `IMessageDialogService`、両者の Windows 実装、`Program` からの注入は実装済み。
- 旧 `SystemClipboard` は削除し、P/Invoke と WinForms `MessageBox` は `Infrastructure/Windows` へ集約済み。
- `IFileDialogService` と共通オプション型、`WindowsFileDialogService` も実装済み。
- SGFの読込・保存、GTPエンジン関連、ログ保存先、SGF保存先のファイル・フォルダー選択はサービス経由へ置換済み。
- WinForms の Open、Save、FolderBrowser は `Infrastructure/Windows/WindowsFileDialogService.cs` だけに残っている。
- `ITextInputDialogService` と共通オプション型、`WindowsTextInputDialogService` も実装済み。
- GTPエンジンの文字列・数値入力フォームはサービス経由へ置換済み。
- WinForms の入力フォーム部品は `Infrastructure/Windows/WindowsTextInputDialogService.cs` だけに残っている。
- 2026-07-28に上記変更後のソリューション全体の Debug ビルドが警告 0、エラー 0 で成功。
- 次は `Process.Start` の用途を分類し、ファイル、フォルダー、URL、エディターを開く処理を `IDesktopLauncher` へ移す。
- 子プロセス通信はデスクトップ起動と分けたままにする。
- その後、文字画像生成を移す。
- 共通コードから Windows API 参照がなくなった段階で、`KifuwarabeGo2026.Gui.Core` と `KifuwarabeGo2026.Gui.Windows` へ分ける。
- 現在の正式対応 OS と配布物は Windows のまま。

## 現在の状態

- ソリューションは `KifuwarabeGo2026.Gui`、`KifuwarabeGo2026.Engine`、`KifuwarabeGo2026.Shared`、`KifuwarabeGo2026.Gui.Communication.Cgos` の4プロジェクト構成。
- `GoBoard`、`GoPoint`、`GoStone`、`GoRenParseResult` はSharedへ移動済み。
- GUIとEngineはSharedを参照し、EngineからGUIへの依存はない。
- CGOS通信クライアントはGUIが外部プロセスとして起動する。
- GTPエンジン設定は表示名とは別に、CGOSのデフォルトログイン名と平文パスワードを保存できる。
- CGOS接続画面では、黒白プレイヤーごとにログイン名とパスワードを接続前に編集できる。
- 利用者向け配布物はGUI版とEngine版の2種類だけ。
- GUIをpublishすると、CGOS通信コンポーネントが `Tools\Cgos` へ自動的にpublishされる。
- SharedはGUI版とEngine版へ自動的に含まれるため、単独publish・単独配布は不要。

## リリース手順

最初に [開発/リリース手順.md](./開発/リリース手順.md) を読む。

リリース用コマンドは次の2本。

```powershell
dotnet publish KifuwarabeGo2026.Gui\KifuwarabeGo2026.Gui.csproj -c Release -r win-x64 --self-contained false
dotnet publish KifuwarabeGo2026.Engine\KifuwarabeGo2026.Engine.csproj -c Release -r win-x64 --self-contained false
```

CGOSとSharedを個別にpublishしないこと。
