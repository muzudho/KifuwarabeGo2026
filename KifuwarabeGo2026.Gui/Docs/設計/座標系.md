# 座標系

最終更新: 2026-08-10

KifuwarabeGo2026 は、**内部・画面描画**と**人に見せる囲碁座標**を分けて扱います。

| 用途 | 原点 | `y` が増える方向 |
| --- | --- | --- |
| 内部の盤配列・画面描画・マウス判定 | 左上 | 下 |
| 囲碁座標の表示・外部プロトコル | 左下 | 上 |

## 内部・画面描画

盤上の内部座標は `(0, 0)` を左上とします。`x` は右へ、`y` は下へ増えます。
これは画面座標系と同じ向きなので、描画、マウス位置からの交点判定、二次元配列の走査を素直に実装できます。`GoScreenRenderer.BoardPoint` はこの座標系を画面上のピクセル座標へ変換します。

## 囲碁としての座標

人に表示する座標、および GTP などの外部プロトコルで扱う座標は、左下を原点とします。内部座標 `(x, y)` を盤サイズ `size` の囲碁座標へ変換するときは、縦方向を反転します。

```text
goY = size - 1 - y
```

この変換は表示・入出力の境界でだけ行います。盤の内部ロジックや描画ループの原点を変更してはいけません。

## 実装時の指針

- 画面へ描くコードは、左上原点の内部座標を使う。
- 座標ラベル、棋譜の説明、GTP 入出力は、左下原点の囲碁座標を使う。
- 2 種類の座標をまたぐ処理には、変換の目的が分かる名前またはコメントを付ける。
