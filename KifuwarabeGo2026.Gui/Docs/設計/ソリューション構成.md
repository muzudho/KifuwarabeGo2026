# ソリューション構成

KifuwarabeGo2026 の機能は、次の三つの領域に分けて整理します。

```text
Go Core       盤面、ルール、座標など
Go Play       通常対局に固有の機能
Go Problems   問題集に固有の機能
```

## Go Core

通常対局と問題集の両方から利用する、囲碁の基礎部分です。

- 盤面と交点
- 石と手番
- 座標
- 連、呼吸点、石取り
- 合法手、コウ、自殺手などのルール

## Go Play

通常の対局に固有の機能です。

- 人間同士の対局
- 人間とコンピューターの対局
- コンピューター同士の対局
- 対局進行、時計、投了、終局
- 対局棋譜

## Go Problems

囲碁問題集に固有の機能です。死活だけに限定せず、将来ほかの種類の問題も扱える領域とします。

- 死活
- 手筋
- 攻め合い
- コウ
- ヨセ
- 次の一手
- 形勢判断

## 依存関係

`Go Play` と `Go Problems` は `Go Core` を利用します。`Go Core` は、通常対局や問題集に固有の機能へ依存しません。

```text
Go Play ──────┐
              ├──> Go Core
Go Problems ──┘
```

この三つは、まずソリューション内の責務を表す呼称として使用します。実際のプロジェクト分割や既存プロジェクトの改名は、必要になった段階で別途設計します。
