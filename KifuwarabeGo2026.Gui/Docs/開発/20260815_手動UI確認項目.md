# 手動 UI 確認項目

自動テストとビルドを通過した後に、実画面でだけ確認できる項目をまとめる。

## ランダムシード入力

- 黒番・白番それぞれで `AUTO` と固定値を入力できる。
- `CLEAR` で空欄へ戻り、次の対局開始時に新しい正の整数が生成される。
- 固定値は連続対局でも維持される。
- `RandomSeed` 非対応エンジンと人間プレイヤーでは入力行が表示されない。
- Local Match と Ponnuki の表示、バッジ、当たり判定が同じ操作感になっている。

## Button 描画

- 動的ボタンへ統一した画面で、文字サイズ、折返し、余白、無効・選択・ホバー表示に不自然な差がない。

確認が済んだ項目はこの文書から削除し、全項目が済んだら `完了` へ移す。
