# Kifuwarabe Go 2026 v2.4.0

棋譜レビューの現在局面から、そのまま独立ホワイトボードへ移って検討・盤面編集できるようにしたリリースです。

## 主な変更

- 棋譜レビュー画面へ、ホワイトボードとマジックペンのアイコンを追加
- 棋譜レビューのチャートポップアップからも、現在局面の検討を開始可能に変更
- 現在表示中のレビュー局面を独立ホワイトボードへ複製し、元棋譜を変更せずに検討可能
- `DISCARD` で検討盤だけを破棄し、元の棋譜レビュー局面へ復帰
- 対局、検討、観戦の盤を分離したまま、盤面表示と操作部品を共通利用する設計へ整理
- 3種類の盤の役割と安全な共通化範囲を開発文書へ記録

## 配布物

- GUI版: `KifuwarabeGo2026.Gui-v2.4.0-win-x64.zip`
- Engine版: `KifuwarabeGo2026.Engine-v2.4.0-win-x64.zip`
