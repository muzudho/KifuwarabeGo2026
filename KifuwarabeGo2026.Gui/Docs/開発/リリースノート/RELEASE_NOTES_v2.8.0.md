# Kifuwarabe Go 2026 v2.8.0

> [!Caution]
> テキストボックスで Delete キーを長押しすると、アプリケーションが強制終了する不具合が v2.8.0 で発生します。v2.8.1 で修正しました。

CGOSの待機・観戦・結果画面を分かりやすく整え、Windowsらしいテキスト編集操作を追加したリリースです。

## 主な変更

- CGOS接続画面で待機中だけ、マッチ成立から10秒後に観戦画面へ自動遷移
- 別画面で作業中は自動遷移を中断し、`対局を観る` ボタンから任意に移動
- CGOS接続欄を `Player1`、`Player2`、`Admin` の利用順へ変更
- Player2とAdminを、必要な場合だけチェックで有効化
- CGOSとローカルの両結果画面から、棋譜レビューとホワイトボードの両方を利用可能
- 横長ウィンドウでも背景と斜線が左右端まで自然に継続
- テキストボックスで貼り付け、選択、コピー、切り取り、選択削除、選択置換、全選択に対応
- `Ctrl+Z`／`Ctrl+Y` による最大100段階のテキスト編集Undo／Redo
- パスワード欄からのコピーと切り取りを禁止
- 日本語字形不足による通知・チェック欄の文字化けを修正

## テスト状況

- 7プロジェクト全体のReleaseビルドを実施
- 移植性スモークとWindowsスモークを実施
- テキスト選択、置換、削除、貼り付け、パスワード保護、Undo／Redoを自動回帰検査
