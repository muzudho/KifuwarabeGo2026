# Kifuwarabe Go 2026 v2.3.0

ライブ対局を追いながら過去局面を再生し、終了後はそのまま検討へ移れるようにしたリリースです。評価値チャート、SGF保存、盤面編集、独立ホワイトボードを一続きの操作へまとめました。

## 主な変更

- ローカル対局とCGOS観戦へ `LIVE` / `REPLAY` 表示を追加
- ライブ中でもチャートやステップボタンから過去局面へ移動できるリプレイ機能を追加
- `LIVEに戻る` とチャートの自動更新切替を追加
- 結果画面のチャートをポップアップ化し、棋譜レビューと共通のシーク操作へ統一
- チャートのScore・WinRate表示とコメント表示を個別に切り替え可能にし、軸ラベルへ `B` / `W` を明記
- チャート上のクリック対象をライブ更新中も保持し、ダブルクリックで意図した局面へ移動
- SGF保存先が設定されている場合の自動保存を、ローカル結果とCGOS観戦・結果へ追加
- 最新着手をターコイズ色のリングで表示
- リプレイ、ライブ、結果画面から独立したホワイトボードを開けるように変更
- ホワイトボードを本対局と別セッションにし、検討中もローカル対局とCGOS受信を継続
- ホワイトボードへ `PLAY`、`BLACK`、`WHITE`、`ERASE`、`CLEAR BOARD`、`UNDO` を追加
- 直接編集した盤面をSGFの `AB[]` / `AW[]` として保存し、その後の検討手を着手列として保存
- セットアップ画面の `EDIT BOARD` を共通ホワイトボードへ統合し、`ADOPT` で初期配置へ採用
- CGOS観戦画面から通信を維持したまま接続画面へ戻る `LEAVE VIEW` を追加
- CGOS対局中のプレイヤー操作を `ABORT` と `RESIGN` に整理
- GUIウィンドウへアプリ固有アイコンを設定
- SGFの `RE[]` パディング、`CC[]` の由来、棋譜ファイル名、囲碁用語の調査記録を追加
