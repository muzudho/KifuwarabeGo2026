# Kifuwarabe Go 2026 v3.9.0

編集・設定画面を日常的に使いやすくし、重なった画面へ入力が漏れないよう整理したリリースです。

## 編集と設定

- PLAYER SELECT と USE CLIENT IDENTITY に `DUPLICATE` を追加しました。既存の設定を複製して、新しいプレイヤーやクライアントIDを作れます。
- PLAYER SELECT のページ送りと ORDER の表示を整理しました。ORDERは半ページずつ送れるため、ページ境界をまたいでカードをドラッグできます。
- アプリケーション設定画面を新UIへ移行しました。設定値は太い角丸アンダーラインで表し、ホバー時だけ右端へ小さな `BROWSE` / `OPEN` バッジを表示します。欄そのもののクリックでも同じ操作を実行できます。
- 画面ごとの操作を `DISCARD` と `SAVE & CLOSE`、または局面編集の `DISCARD` と `ADOPT` へ統一しました。保存が成功した編集画面は自動的に閉じます。
- 保存中はローディングスピナーを表示します。

## 画面遷移と入力

- `DISCARD` 時だけ、紙が稲妻で左右へ裂ける演出を追加しました。
- アクティブウィンドウスタックを導入しました。最前面のダイアログだけがクリック・ドラッグを受け取り、背後の画面へ入力が漏れません。
- プレイヤー、クライアントID、GTPエンジン、大会ルール、CGOS、各種入力ダイアログ、棋譜グラフ、局面編集、アプリケーション設定、CGOS対局通知を対象にしました。
