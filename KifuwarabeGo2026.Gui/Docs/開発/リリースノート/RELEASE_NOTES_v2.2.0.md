# Kifuwarabe Go 2026 v2.2.0

棋譜の互換性とレビュー機能を強化し、設定・保存先の扱いとチャート表示を改善したマイナーリリースです。

## 主な変更

- CGOS接続設定をアプリケーション設定へ統合し、利用者の実設定を `%LOCALAPPDATA%\KifuwarabeGo2026` 以下へ保存
- CGF OPEN 2026の接続先と大会設定をデフォルト登録
- 棋譜の保存先をアプリケーション設定で指定可能にし、未設定時は最初に利用したフォルダーを記憶
- `SGF INPUT` でも同じ棋譜フォルダーを初期表示
- SGFを読みやすい複数行形式で出力
- `CC`、`KFA`、`C` を互換性を保ちながら読み書きし、既存のCGF Open棋譜コメントを表示
- `TM`、`AP`、`WR`、`BR`、`DT`、`RE`、`PC`、`GN` などのSGFメタデータを保持
- 棋譜レビュー画面へ評価値チャートとコメント表示を追加
- ローカル対局、対局結果、CGOS観戦でもチャートとコメントを切替可能
- コメントがある着手をチャート上の `*` で表示
- 長いコメントをページ分割して大きな文字で表示
- 棋譜レビューの前後移動へキーリピートとボタン長押しリピートを追加
- 棋譜の先頭・末尾へ移動するボタンを追加
- 盤面の上へ半透明で重ねる大型チャートポップアップを追加
- ポップアップ上でクリック、ドラッグ、ダブルクリックによる棋譜ナビゲーションに対応
- コンピューター同士のローカル対局とCGOS観戦では、局面移動を行わない閲覧専用ポップアップとして利用可能
- ポップアップ表示中は背景の操作部を隠し、盤面への誤入力を防止
- チャートの軸、目盛り、評価値、優勢表示、シーク案内の文字を拡大
