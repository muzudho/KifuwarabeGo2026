# Kifuwarabe Go 2026 v3.13.0

画面描画の責務分割を大きく進め、棋譜レビュー、ランダムシード、文房具 UI を改善したリリースです。

## 画面構造

- 巨大化していた `GoScreenRenderer` を、画面状態、描画部品、操作処理の三層へ段階的に分割しました。
- タイトル、盤、GTP エンジン、CGOS、棋譜グラフなどを専用 Renderer / Page / Component へ整理しました。
- 右サイドパネルとヘッドアップディスプレイを共通部品化しました。
- ファイルパスのツールチップ、保存中表示、パンくず、アクションバッジなどの共通 UI を整理しました。

## 棋譜レビュー

- 対局結果画面を棋譜レビュー画面へ統合しました。
- 棋譜コメントの編集と表示を改善し、編集に関する回帰不具合を修正しました。
- シークボタン列を共通部品化し、操作の回帰不具合を修正しました。

## ランダムシード

- ローカル対局、CGOS、ポン抜きゲームのランダムシードを画面から設定できるようにしました。
- ランダムシード入力行を共通 UI 部品として整理しました。
- 設定 ID の重複検査を追加し、不正な重複を早期に検出できるようにしました。

## 文房具 UI

- 旧 `DrawCommandButton` の定義と C# 呼び出しをすべて廃止しました。
- 動的ボタンを含め、ボタン描画を文房具 UI の `Button` クラスへ統一しました。
- 顔文字で利用する全角記号を UI フォントへ追加しました。

## 配布物
