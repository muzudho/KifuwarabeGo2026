# 開発日誌 2026年8月

## 2026-08-01

### Matchプロジェクトの分離

- ローカル対局の中核を `KifuwarabeGo2026.Match` へ分離しました。
- MatchはWindows、GUI、通信、外部プロセスへ依存せず、将来のUbuntu上の囲碁サーバーからもラッピングできる `net8.0` ライブラリです。
- 盤サイズ、コミ、初期配置、開始手番、着手、パス、投了、手数上限、履歴をMatchで管理します。
- 人間対コンピューターとコンピューター同士を含むローカル対局をMatchへ接続しました。
- サーバー確定時計のスナップショットと観戦イベント、黒白の結果申告、合意、再開、審判裁定を追加しました。
- 認証、WebSocket、永続化、審判権限確認はMatchへ入れず、将来のサーバー側ラッパーが担当する境界を維持しました。

### GtpExtensionsと指定局面コンシェルジュ

- `KifuwarabeGo2026.GtpExtensions` を追加し、Windows、MonoGame、GUI、Engine、外部プロセスに依存しない指定局面互換層を作りました。
- 初期局面を空、標準置き碁、自由置き碁、黒白混在、履歴依存へ分類します。
- 9路、13路、19路の標準置石、GTP座標、`fixed_handicap`、`set_free_handicap`、`loadsgf`、連続 `play` のStrategyを追加しました。
- `name`、`version`、`known_command`、`list_commands` を使い、Supported、Unsupported、Unknownと診断根拠を保持する能力検査を追加しました。
- `loadsgf` 用の最小SGFをUTF-8 BOMなしで一時保存し、AB、AW、PL、SZ、KMとパス引用方式に対応しました。
- 明確なコマンド拒否だけを自動フォールバックし、未検証成功、局面不一致、想定外応答、通信障害では利用者判断を待つConciergeを実装しました。
- 黒番と白番の2エンジンは、能力、試行履歴、診断、次方式、承認状態を独立して保持します。

### 指定局面GUI

- 初期石のあるコンピューター対局で、右側へ［指定局面コンシェルジュ］を表示するようにしました。
- 方式ごとの成功、未確認、非対応、拒否、不一致、想定外応答、通信失敗を画面へ表示します。
- ［別の方法を試す］［このまま続ける］［GTP LOG］［CANCEL］をマウスとキーボードで操作できます。
- 全エンジンが検証済みまたは利用者承認済みになるまで、思考開始を抑止します。
- 日本語を英数字用SpriteFontへ渡した文字化けを、OS文字ラスタライズ経路へ切り替えて修正しました。
- コンシェルジュのクリックが背後の小型チャートへ伝播する問題を修正しました。

### エンジンProfileと成功方式の保存

- Generic、Kifuwarabe、KataGo、Leela Zero、GNU Goの互換Profileを追加しました。
- エンジン編集画面の `POSITION` 欄で、Profileと手動優先方式を選択できます。
- 自動確認または利用者承認された方式を、エンジン名、version、Profileと一緒に保存します。
- 同じ組み合わせでは成功方式を優先し、nameまたはversionが変わった場合は自動結果だけを破棄して再検査します。
- Profileへ `ConservativeFallback`、`OfficialDocumentationOnly`、`BundledEngineVerified` の証拠区分を追加しました。
- 外部エンジンを実機確認していない状態を成功扱いしない方針を、コードと検証文書の両方へ反映しました。

### きふわらべ原子的指定局面プロトコル

- 先に独自GTP拡張仕様を作り、準備盤、commit、abort、失敗時の通常盤保護を定義しました。
- Engineへ `begin_position`、`add_black`、`add_white`、`set_to_play`、`commit_position`、`abort_position` を追加しました。
- 黒白混在、呼吸点のない石、通常の着手順では作れない自由編集形を準備盤へ直接配置できます。
- 成功した `commit_position` だけが実対局盤を置き換え、エラーまたはabortでは準備盤を破棄します。
- 全6コマンドを `known_command` と `list_commands` へ追加し、きふわらべProfileの最優先Strategyへ接続しました。

### 検査と文書

- 同梱Engine.exeをGUI本番と同じ外部プロセス経路で起動し、能力検査、Profile自動選択、Concierge、原子的commit、`VerifiedSuccess`まで自動検査します。
- 移植性スモークへ分類、Strategy、SGF、能力検査、フォールバック、Profile、JSON保存の回帰検査を追加しました。
- Windowsスモークへ黒白混在、呼吸点のない編集形、重複、盤外、commit失敗、通常盤保護、abortの検査を追加しました。
- 指定局面コンシェルジュ利用ガイド、エンジン検証結果、原子的指定局面GTP拡張仕様を追加しました。
- 利用者による実画面確認で、きふわらべを使った指定局面戦が開始できることを確認しました。
