# LocalMatch ランダムシード入力 UI 設計

## 目的

LocalMatch のランダムシード指定を、自動変更チェックボックスから、空欄を AUTO と解釈する数値リンク入力へ置き換える。

## 仕様

- 選択中のプレイヤーが人間、またはエンジンが `RandomSeed` GUI オプションを持たない場合は入力欄を表示しない。
- 対応エンジンでは黒番・白番ごとにリンクアンダーラインを表示する。
- 保存値が空文字ならリンクアンダーラインにはプレースホルダー `AUTO` を表示する。
- リンクを押すと文房具 UI の `PopupNumberUnderline` を開く。
- ポップアップにはエンジンオプションの `min` / `max` を表示する。
- `PopupNumberUnderlineOptions.AllowEmpty` が有効な場合、空欄を正常な確定値として扱う。
- 空欄なら対局開始時にシードを生成し、整数ならその値をそのままエンジンオプションへ渡す。
- 入力値は選択中のエンジンプロファイルに保存し、連続対局でも維持する。
- 初期値は空文字とする。

## 責務分担

### LinkUnderline

- `Placeholder` を持つ。
- 実値が空の場合だけプレースホルダーを表示値として返す。
- 実値に `AUTO` という文字列は保存しない。

### PopupNumberUnderline

- `PopupNumberUnderlineOptions.AllowEmpty` を持つ。
- 空欄を許可するかどうかは呼び出し側の検証へ伝える。
- 数字入力、選択、キャレット、min/max の案内表示は既存機能を使う。

### GoAppSession

- 対応判定、選択エンジンの値の取得・保存、対局開始時の AUTO 解決を担当する。
- AUTO は対局ごとに正の整数を生成する。

## 移行進捗

### 調査完了

- 既存の自動変更チェック方式と開始時シード適用経路を棚卸しした。
- 共通 UI の拡張方針を決定した。

### 完了

- `LinkUnderline.Placeholder` の追加。
- `PopupNumberUnderlineOptions.AllowEmpty` の追加。
- LocalMatch のリンク表示、ポップアップ入力、保存処理への置換。
- 旧 SEED AUTO チェックボックスおよび LocalMatch 専用の自動変更フラグを撤去。
- 空欄時の対局ごとのシード生成と、固定値の連続利用を実装。
- 初期エンジン一覧の `RandomSeed` を空文字へ変更。
- 区画ラベルを `RANDOM SEED` とし、BLACK / WHITE の文字ラベルを石アイコンへ変更。
- リンクアンダーラインへホバーしたときに `CHANGE` アクションバッジを表示。
- 数字ポップアップを下線表示へ統一し、見出しと入力文字の重なりを解消。
- ソリューション全体のビルド成功（警告 0、エラー 0）。
- PortabilitySmoke と WindowsSmoke の成功。

### 未完了
