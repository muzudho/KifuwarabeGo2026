# Linux・macOS GUI移植計画

作成日: 2026-08-01

## 目的

Windows依存の分離後に残る、Linux版とmacOS版の起動プロジェクトおよびOS固有サービスを実装する。

## 前提

- 現在の正式対応OSと配布物はWindowsである。
- 共通GUIは `KifuwarabeGo2026.Gui`、Windows実装は `KifuwarabeGo2026.Gui.Windows` に分離済みである。
- `KifuwarabeGo2026.Gui.PortabilitySmoke` は移植用の最小構成例として利用できる。

## 実装段階

1. 対象OSで共通GUIと移植性スモークをビルド・実行する。
2. LinuxまたはmacOSの起動プロジェクトを追加する。
3. ファイル選択、クリップボード、外部アプリ起動、ダイアログを対象OS用に実装する。
4. Content読込、設定・ログ保存先、文字入力、ウィンドウアイコンを確認する。
5. 対象OSのCIと手動スモークテストを追加する。
6. 配布形式を決め、対応OSとして案内できる条件を満たす。

## 要調査

- SDL2アイコン処理で使うライブラリ名とウィンドウハンドルの取得方法。
- ファイルダイアログと既定アプリ起動に採用するOS別API。
- macOSのアプリバンドル、署名、公証を初回配布範囲へ含めるか。
- Linuxの対象ディストリビューションと必要なネイティブ依存。

## 完了条件

- 対象OSでGUIを起動し、ローカル対局と主要なファイル操作を確認できる。
- 対象OSの自動検査と手動確認手順がある。
- Windows版のビルド、スモーク、配布手順を壊していない。
