# 結果画面・棋譜レビュー画面統合計画（完了）

完了日: 2026-08-15

## 目的

ローカル対局終了後の独立した［結果画面］を廃止し、棋譜レビューのタイムライン終端に `RESULT` を追加する。

```text
初期局面 ─ 1手目 ─ … ─ 最終手 ─ RESULT
   0          1             N       N+1
```

`RESULT` は棋譜上の架空の一手ではなく、レビューUIだけが持つ終端状態とする。

## 完了した実装

### レビュータイムライン

`GoAppSession.LocalReplay` に次を追加した。

- `IsLocalResultPosition`
- `LocalReviewTimelineIndex`
- `LocalReviewTimelineMaximum`
- `SeekLocalReviewTimeline(int)`

終局直後はローカルリプレイ位置がないため、`Moves.Count + 1` のRESULT位置になる。

- RESULTから一手戻すと `Moves.Count`、つまり最終手位置へ移る
- 最終手から一手進めるとRESULTへ戻る
- Homeは0手目へ移る
- EndはRESULTへ移る
- ±1、±10、±50、キーボードリピート、マウス長押しもRESULT境界を利用する

`SeekLocalReplay` はGameOver中に最終手位置をRESULTへ自動変換しないよう変更した。これにより「最終手」と「結果」が別のタイムライン位置になった。

### 統合表示

`ReviewingRightSidePanel` が通常レビューと終局後レビューの両方を描画する。

- RESULT位置: `GAME RESULT`、終局手数、ルール、勝敗理由、SGF出力を表示
- 着手位置: `KIFU REVIEW` と `STEP N / M` を表示
- 共通: 盤面、形勢グラフ、先頭・末尾・増減ナビゲーションを表示
- RESULTは `STEP M+1` ではなく、明示的に `RESULT` と表示
- パンくずはRESULTで `PLAY > REVIEW > RESULT`、着手位置で `PLAY > REVIEW`

対局終了時は従来どおり内部的に `GameOver` へ遷移するが、その初期表示が統合レビューのRESULT位置になるため、［KIFU REVIEW］を押す段階はなくなった。

### 削除した独立結果画面

- `GameOverRightSidePanel`
- `LocalMatchScreen.GameOverRightSidePanel`
- `LocalMatchScreen.GameOverReviewButton`
- `LocalMatchScreen.ReturnToSetupButton`
- `LocalMatchScreen.ExportSgfButton`
- 結果画面から棋譜レビューを開始するクリック分岐
- 旧結果画面専用のSGFクリック分岐

SGF出力とホーム復帰は `BoardAndReviewScreen.Review` の操作へ移した。

### 名称整理

終局後レビューで引き続き利用するチャート・コメント機能は、独立結果画面の機能ではなくなったため、コード上の `LocalGameOver` 名を `CompletedLocalGame` へ変更した。

## 設計上残したもの

### GoAppModeKind.GameOver

`GameOver` は表示画面ではなく、次の終局処理を安全に完了させる内部状態として残した。

- エンジン停止
- 時計停止
- 自動保存
- 終局音
- Match連携終了

表示目的の `GameOverRightSidePanel` は削除済みである。将来、これらを画面モードに依存しない終局イベントへ分離できた段階で、`GameOverMode` 自体を削除できる。

### CGOS結果状態

`CgosConnectionFlowKind.Result` は通信通知、観戦状態、SGF自動保存、通信プロセス状態を持つため、今回のローカル結果画面廃止には含めていない。ローカルのRESULTタイムラインと通信状態を同じ列挙値へ混ぜない。
