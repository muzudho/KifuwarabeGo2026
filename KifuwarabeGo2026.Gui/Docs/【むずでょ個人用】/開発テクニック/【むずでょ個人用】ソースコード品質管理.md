# 【むずでょ個人用】ソースコード品質管理


## セクションコメント

（１）以下のように、コを左右逆にした形のコメントを、  
このプロジェクトでは［セクションコメント］と名付けるぜ（＾～＾）  
長い部分のスラッシュの数は 40 個。  

```csharp
////////////////////////////////////////
//
////////////////////////////////////////
```

（２）以下のようにセクション名を付けるぜ（＾～＾）  

```csharp
////////////////////////////////////////
// 生成
////////////////////////////////////////
```


## セクションコメントの使い方

構造はフラットであり、上から下の順序を持つ。つまりリストと同じだぜ（＾～＾）  

```csharp
////////////////////////////////////////
// 生成
////////////////////////////////////////

////////////////////////////////////////
// データメンバー
////////////////////////////////////////

////////////////////////////////////////
// 機能
////////////////////////////////////////
```

どのようなセクションがあるかは、任意だが、だいたい他のソースコードと合わせていくぜ（＾～＾）
